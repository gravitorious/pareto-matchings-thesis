## Description

This repository contains the LaTeX source code of my Master's Thesis.

The thesis studies matching problems in graphs, focusing on both settings where preferences are present and where they are absent. Particular emphasis is given to Pareto optimal matchings and the structural properties that characterize them.

The work investigates theoretical aspects of matching theory, including fundamental concepts, structural results, and algorithmic approaches. In addition, polyhedral formulations and linear programming techniques related to matching problems are examined.
