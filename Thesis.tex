\chapter*{Preface}
	
	Consider the case where there are $n$ teachers and we have to decide which schools to assign them to based on some criteria. For example, each teacher may have preferences over the available schools, while schools may have specific ranking criteria based on their teaching needs. Similarly, $n$ applicants may have preferences over houses they want to buy. There is only one side with preferences, but we still have two sides we want to match. An example with more than two sides is when we have a set of professors, projects, and students, and our purpose is to assign each project to a professor and then assign students to each project. Here, each assignment is a triplet, and there could be many criteria. Despite the preferences of each side, we may instead be interested in maximizing or minimizing a different criterion. For example, in the teacher assignment problem, we may want to maximize the number of schools that receive a teacher without taking the teachers' preferences into account. Matching problems arise in many different forms and areas, and the underlying requirements may vary depending on the application.
	
	The algorithmic study of matchings has played an important role in the development of combinatorial optimization. While some matching problems admit elegant strongly polynomial algorithms, even small modifications of the underlying model may lead to computationally difficult problems.
	
	The big effect of matching theory on real-world economics and society was notably recognized in $2012$, when Alvin E. Roth and Lloyd S. Shapley were awarded the Nobel Prize in Economic Sciences. Their recognition was rooted in the theory of stable allocations, which originated in the foundational $1962$ work by David Gale and Lloyd Shapley \cite{Gale01011962}.
	
	Many problems in Economics, Engineering, and Computer Science can be modeled exactly or approximately using linear functions. Linear Programming has numerous applications across these areas, making it one of the most widely applied branches of Mathematics. It is a relatively new science, born to meet the demands of the Second World War. During the early years of its development, the simplex algorithm dominated. Later, polynomial-time methods, such as the ellipsoid method and interior-point algorithms, were developed, providing important theoretical and practical advances, particularly for large-scale optimization problems \cite{schrijver2003volA}.
	
	In integer programming, many natural decision variables are restricted to take values of zero or one, representing whether an object is selected, an edge is used, or an assignment is made. However, solving integer programs directly is generally difficult. A common strategy is therefore to relax the integrality restrictions and study the corresponding linear program. When the feasible region of the relaxation is integral, an optimal integer solution can be obtained by solving the corresponding linear program.
	
	The purpose of this thesis is to study matching problems on bipartite graphs from both of these perspectives. We first present classical algorithmic results for two fundamental problems in matching theory and then study related formulations through linear and integer programming. The final part of the thesis focuses on a Pareto optimal matching problem in a one-to-one house-allocation model, where the behavior of the linear relaxation is substantially more complicated.
	
	Chapter $1$ is about matching problems and algorithms. After introducing the basic definitions, we present a classical augmenting-path implementation with running time $O(nm)$, where $n$ denotes the number of vertices and $m$ the number of edges. We then give an implementation of the Hopcroft--Karp algorithm, which improves the running time to $O(\sqrt{n}(n + m))$ by finding many shortest augmenting paths in phases. We continue with the stable marriage problem and the Gale--Shapley algorithm, one of the most famous algorithms in matching theory.
	
	The main focus of this chapter is the presentation of the algorithms. The above algorithms are often described in the texts without the implementation details. Our pseudocode is written in a detailed form, so that their translation into an actual programming language is almost straightforward. Moreover, the proofs are adapted to the implementations rather than being presented only at a high conceptual level. This makes the connection between the code, the algorithmic idea and the correctness argument explicit.
	
	Chapter $2$ introduces the polyhedral point of view. We first recall the basic language of linear programming, integer programming, polyhedra, polytopes, and integrality. We then return to the matching problems studied in Chapter 2 and examine them through linear and integer programming formulations. For the maximum bipartite matching problem, the linear relaxation captures the integer structure of the problem, and as a result we can get the optimal matching solutions through linear programming. A similar phenomenon appears in the stable marriage problem, where the corresponding stable matching polytope has an integral linear description. 
	
	Chapter $3$ studies Pareto optimal matchings in a one-to-one house allocation model. Here, applicants have strict preference lists over houses, and the aim is to describe Pareto optimal matchings. We present the known integer programming formulation for this problem and then study its linear relaxation. Unlike the classic examples in Chapter $3$, the relaxation is not generally integral. With the help of a software, we construct a fractional optimal solution of the relaxation that does not correspond to a convex combination of Pareto optimal matching vectors.
	
	We show that a family of constraints in the formulation can be very large. To handle this, we use a separation approach. So, instead of listing all such constraints in advance, we search for violated constraints only when they are needed. This allows the relaxation to be solved more efficiently in practice and enables computational experiments on small instances.
	
	One of the main focuses is to compare the linear relaxation with the actual convex hull of Pareto optimal matching vectors. We construct some small instances, we enumerate Pareto optimal matchings, compute the corresponding convex hull, and derive its linear description. With this, we are able to identify which inequalities are valid for the true Pareto optimal matching polytope but are not enforced by the original relaxation. From these experiments, we prove two families of additional valid inequalities: prefix-cover inequalities and safe-holder inequalities. These constraints strengthen the relaxation and specifically the first one gives us an upper bound for the dimension of Pareto optimal matching polytope. Finally, for a cyclic parametric family of house allocation instances, we derive a new family of cycle-break inequalities and prove that they are facet-defining for the corresponding Pareto optimal matching polytope. Although this result concerns only a specific family, it illustrates a possible approach for further polyhedral analysis.
	
	The prerequisites for this thesis are typically covered in an undergraduate curriculum, such as graph theory, algorithms, computational complexity, and linear algebra. Basic knowledge of these fields is enough to follow the content of this thesis.

\chapter{Matching Problems and Algorithms}

\section{Definitions}

	Let $G = (V,E)$ be a simple (without loops and parallel edges) undirected graph with $|V| = n$ vertices and $|E| = m$ edges. We call $G$ bipartite if we can partition its vertex set into two sets $V_{1}, V_{2}$ such that for each edge $\{u,v\} \in E$, one endpoint belongs to $V_{1}$ and the other to $V_{2}$. If every vertex of $V_{1}$ is adjacent to every vertex of $V_{2}$ and $|V_{1}| = n_{1}, |V_{2}| = n_{2}$, then we call $G$ a complete bipartite graph and denote it by $K_{n_{1},n_{2}}$. By a path, we mean a simple path, i.e., a path in which no vertex is repeated. The length of a path is the number of edges it contains.

	From set theory, we recall that the symmetric difference of two sets $A$ and $B$, denoted by $A\bigtriangleup B$, is the set of elements that belong to $A$ or $B$ but not both. Thus, $A\bigtriangleup B = (A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$. Also, if we want to add an element $x$ to set $A$, we will use the shorthand $A + x \coloneqq A \cup \{x\}$, and if we want to remove it $A - x \coloneqq A \setminus \{x\}$.

	For non-negative functions $T$ and $f$, we write $T(n) = O(f(n))$ if and only if there exist positive constants $c$ and $n_{0}$ such that $T(n) \leq c f(n)$ for all $n \geq n_{0}$. Most of the time, $T(n)$ will denote a bound on the worst-case running time of an algorithm defined on the positive integers. Similarly, we say that $T(n) = \Omega(f(n))$ if and only if there exist positive constants $c$ and $n_{0}$ such that $T(n) \geq cf(n)$ for all $n \geq n_{0}$. Finally, we say that $T(n) = \Theta(f(n))$ if and only if $T(n) = O(f(n))$ and $T(n) = \Omega(f(n))$.

	A matching $M$ of a graph $G = (V,E)$ is a subset of $E$ such that each vertex is incident to at most one edge of the subset. The cardinality of a matching is the number of edges it contains. A vertex is called matched if it is incident to an edge of $M$. Otherwise, it is called unmatched or free. A matching is called maximal if no edge from $E \setminus M$ can be added without violating the matching property. A matching is maximum if no other matching has more edges. Clearly, every maximum matching is maximal (the converse is not always true). The following two definitions are fundamental in the study of matchings.
	
	\begin{ddef}
		A path $P$ in $G$ with respect to a matching $M$ is called alternating if its edges are alternatingly out of and in $M$.
	\end{ddef}
	
	\begin{ddef}
		A path $P$ in $G$ with respect to a matching $M$ is called augmenting if it has positive length, is alternating, and its endpoints are free.
	\end{ddef}
	
	It is straightforward to see that every augmenting path has odd length. We will use the term $M$-augmenting whenever we want to emphasize the matching $M$.
	
\section{Maximum Bipartite Matching} \label{2.2}
	In this section, we present two famous algorithms for finding a maximum bipartite matching and prove their correctness.

	The first algorithm is derived from a theorem of Berge \cite{berge1957}, previously observed by Petersen \cite{petersen1891theorie}.

	\begin{ttheorem}\label{BergeTheorem}
		Let $G = (V,E)$ be a graph and let $M$ be a matching in $G$. Then $M$ is maximum if and only if there is no $M$-augmenting path in $G$.
	\end{ttheorem}
	\begin{proof}
		Suppose that $M$ is maximum. For the sake of contradiction, assume that there exists an $M$-augmenting path $P$ with $u$ and $v$ as its endpoints in $G$. Then we can see that the matching $M^{'} = M \bigtriangleup E(P)$ is a valid matching in $G$ and satisfies $|M^{'}| = |M| + 1$. Indeed, if we remove all edges of $P$ that belong to $M$ and add the remaining ones to $M$, we add one more edge to $M$ in total (because $P$ has odd length). The new matching is valid because $u$ and $v$ were free, and they were not incident to any matching edge, and every internal vertex of $P$ remains incident to exactly one edge of $M^{'}$. All vertices outside $P$ are unaffected. As a result, the new matching $M^{'}$ is valid and its cardinality is greater than that of $M$. This is a contradiction.

		Now suppose that $G$ does not contain any $M$-augmenting path and that a matching $M^{'}$ exists in $G$ such that $|M^{'}| > |M|$. Consider the subgraph $G_{0} = (V, M_{0})$ where $M_{0} = M \bigtriangleup M^{'}$. Each vertex in $G_{0}$ may be matched in both matchings or in either one. So, every vertex has degree at most $2$. Hence, every component of $G_{0}$ is either a path or a cycle of even length (otherwise, there would exist a vertex that is incident to two edges in the same matching). Because $M_{0}$ has more edges of $M^{'}$ than of $M$, this also means that there exists a path $P$ with more edges of $M^{'}$ than of $M$. Necessarily, the edges of this path are alternating (otherwise a vertex would be incident to more than one edge of the same matching) and its endpoints are free with respect to $M$. Hence, $P$ is an $M$-augmenting path, which contradicts our assumption that $G$ does not contain any $M$-augmenting path.
	\end{proof}

	\subsection{Augmenting-Path Algorithm}

	Based on the theorem above, we can write an algorithm that will try to find an augmenting path, alternate its edges (this will increase the size of the current matching by one), and repeat the whole process until we can't find any augmenting path. $N(v)$ represents all the vertices $u$ such that $\{v, u\} \in E(G)$. 

	\begin{algorithm}[H]
	\caption{Augmenting Path Algorithm}
	\label{DfsAugmentingPath}
	\begin{algorithmic}[1]
	\Require Graph $G=(V,E)$, vertex $v$
	\Ensure Array matched such that $\mathit{matched}[u] = v$ and $u \in V_{2}$ and $v \in V_{1}$ if and only if $\{u, v\} \in E(G)$ belongs to the matching
	\Function{DfsAugmentingPath}{\texttt{int} $v$, \texttt{bool} $\mathit{visited}[]$, \texttt{int} $\mathit{matched}[]$}	
		\If{$\mathit{visited}[v]$}
			\State \Return \False;
		\EndIf
		\State $\mathit{visited}[v]$ \gets \True;
		\ForAll{$u \in N(v)$}
		   \If{$\mathit{matched}[u] = \emptyset \textbf{ or } \Call{DfsAugmentingPath}{\mathit{matched}[u], \mathit{visited}, \mathit{matched}}$}
				\State $\mathit{matched}[u] \gets v$;
		        \State \Return \True;
		    \EndIf
		\EndFor
		\State \Return \False;
	\EndFunction
	\end{algorithmic}
	\end{algorithm}
	
	\Cref{DfsAugmentingPath} is getting called from all vertices in the left part of bipartite graph (let's call it $V_{1}$). We will use an extra array called $\mathit{visited}$ to track the vertices from $V_{1}$ that we have already visited across the path and we have to reset it to be false for all these vertices before the initial call. Array matched marks the matched vertices only from the right part of the bipartite graph (let's call it $V_{2}$).  To get the edges of the matching, we simply take all the edges $\{v, \mathit{matched}[v]\}$ such that $\mathit{matched}[v]$ is not empty and store them to set $\mathit{matching}$.

	\begin{algorithm}[H]
	\caption{Maximum Bipartite Matching in $O(nm)$}
	\label{max-bm1}
	\begin{algorithmic}[1]
	\Require Bipartite graph $G=(V_1 \cup V_2,E)$
	\Ensure Set $\mathit{matching}$ that corresponds to the edges of the maximum matching
	\Function{MainAugmentingPath}{\texttt{Graph} $G$, \texttt{set} $\mathit{matching}$}
		\ForAll{$v \in V_{2}$}
			\State $\mathit{matched}[v] \gets \emptyset$;
		\EndFor
		\ForAll{$v \in V_{1}$}
			\ForAll{$u \in V_{1}$}
				\State $\mathit{visited}[u] \gets \False$;
			\EndFor
			\State \Call{DfsAugmentingPath}{$v$, $\mathit{visited}$, $\mathit{matched}$};
		\EndFor
		\State $\mathit{matching} \gets \emptyset$;
		\ForAll{$v \in V_{2}$}
			\If{$\mathit{matched}[v] \neq \emptyset$}
				\State $\mathit{matching} \gets \mathit{matching} \cup \{\{\mathit{matched}[v], v\}\}$;
			\EndIf
		\EndFor
		\State \Return $\mathit{matching}$;
	\EndFunction
	\end{algorithmic}
	\end{algorithm}

	The idea is that if the initial call is from a free vertex, say $v$, and we cannot find another free vertex $u$ such that the edge $\{v, u\}$ exists, then we simply try to find a path $(v,x,y)$ such that $\{v,x\}$ is not in the matching, but $\{x, y\}$ is, so we can start trying again from the vertex $y$, until we find a free vertex and then recursively alternate the path. 
	
	\begin{llemma} \label{callaugmdfs}
		An initial call to \Cref{DfsAugmentingPath} from a free vertex $v \in V_{1}$ (assuming that $\mathit{visited}[w] = \False$ for every $w \in V_{1}$ before the call) returns $\True$ if and only if there exists an augmenting path with endpoint $v$. In this case, it alternates the edges of such a path.
	\end{llemma}
	
	\begin{proof}
		Suppose that a free vertex $u \in V_{2}$ exists such that $\{v,u\} \in E(G)$. Then from line $7$ the algorithm successfully finds an augmenting path. Now suppose that such a vertex doesn't exist and $P=(v,v_{1},v_{2},...,u)$ any augmenting path with the vertex $v$ as its endpoint. Since $P$ is alternating, the edge $\{v, v_{1}\}$ does not belong to the matching, while $\{v_{1}, v_{2}\}$ does. Because the algorithm checks all neighbors of $v$ (line $6$), it will eventually examine $v_{1}$ (assuming that all the other neighbors, if they exist, return false), and line $7$ does a recursive call for $\mathit{matched[v_{1}]} = v_{2}$ (note that $v_{2}$ is impossible to be visited, otherwise an alternative path $(v,...,v_{2})$ exists and the algorithm would have already found another augmenting path from that recursive call to $u$ or to another free vertex). Repeating the same argument along $P$, the algorithm eventually reaches the free vertex $u \in V_{2}$, where line $7$ is true since $\mathit{matched[u]} = \emptyset$. The recursive calls then return $\True$ and update the array matched accordingly, thus alternating the edges of $P$.
		
		Conversely, if the algorithm returns $\True$, then this can only happen because it reaches a free vertex of $V_{2}$, either directly or through recursive calls. Tracing these successful recursive calls backwards gives an alternating path from $v$ to a free vertex of $V_{2}$, and the updates of $\mathit{matched}$ alternate the edges of this path.
	\end{proof}

	From this, we get the following remark.
	\begin{rremark} \label{remarkaugm}
   	 	After an initial call of \Cref{DfsAugmentingPath} from a free vertex $v \in V_{1}$, the only vertices that can become matched are $v$ and one free vertex of $V_{2}$. If no augmenting path is found, then the matching remains unchanged.
	\end{rremark}

	Then, we can prove the following lemma.
	
	\begin{llemma}\label{initial-call-dfs-augm}
    	Every initial call to \Cref{DfsAugmentingPath} from \
    	
    	
    	{max-bm1} takes a free vertex as parameter.	
	\end{llemma}
	\begin{proof}
		This is obviously true in the first iteration. Assume that we are at iteration $i$, and that the statement holds for all previous iterations. Let $v$ be the vertex from which we are about to initially call \Cref{DfsAugmentingPath}. If $v$ is free, then we are done. If it is not, $v$ must have become matched during some previous iteration. However, by \Cref{remarkaugm}, in each iteration the only vertex of $V_1$ that can become matched is the vertex from which \Cref{DfsAugmentingPath} was initially called. Since \Cref{DfsAugmentingPath} has never been initially called from $v$ before iteration $i$, the vertex $v$ could not have become matched earlier.
	\end{proof}
	
	The output of the \Cref{max-bm1} (set matching) is always a valid matching. Since the algorithm initializes with an empty matching and only updates it by alternating edges along valid augmenting paths starting from free vertices (\Cref{callaugmdfs}), the maintained set of edges is always a valid matching. Now we have to prove that it is maximum.

	\begin{ttheorem}
		\Cref{max-bm1} returns a maximum matching.
	\end{ttheorem}

	\begin{proof}
		Let $v_{1},v_{2},\dots,v_{k}$ be the vertices of $V_{1}$ in the order in which \Cref{max-bm1} processes them. For each $i \in \{0,1,\dots,k\}$, let $M_{i}$ be the matching after the first $i$ iterations of the algorithm, with $M_{0} = \emptyset$. Also, let $G_{i}$ be the subgraph of $G$ induced by the vertex set $\{v_{1},v_{2},\dots,v_{i}\} \cup V_{2}$.
		We will prove by induction on $i$ that $M_{i}$ is a maximum matching of $G_{i}$.
	
		For $i=0$, the graph $G_{0}$ has no vertices in $V_{1}$, so the empty matching $M_{0}$ is trivially maximum.
	
		Now assume that $M_{i}$ is a maximum matching of $G_{i}$, and consider iteration $i+1$, where the algorithm processes the vertex $v_{i+1}$. By \Cref{initial-call-dfs-augm}, the initial call to \Cref{DfsAugmentingPath} is made from a free vertex. We consider two cases.
	
		\medskip
		\noindent\textbf{Case 1:} $\Call{DfsAugmentingPath}{v_{i+1}}$ (\Cref{DfsAugmentingPath} with parameter the vertex $v_{i+1}$) returns $\True$. Then, by \Cref{callaugmdfs}, the algorithm finds an augmenting path in $G_{i+1}$ with endpoint $v_{i+1}$ and alternates its edges. Therefore,
		\[
		|M_{i+1}| = |M_{i}| + 1.
		\]
		On the other hand, any matching of $G_{i+1}$ can use at most one edge incident to the new vertex $v_{i+1}$. Hence, by removing that edge if it exists, we obtain a matching of $G_{i}$, and therefore every matching of $G_{i+1}$ has size at most $|M_{i}| + 1$. Since $M_{i}$ is maximum in $G_{i}$, it follows that $M_{i+1}$ is a maximum matching of $G_{i+1}$.
	
		\medskip
		\noindent\textbf{Case 2:} $\Call{DfsAugmentingPath}{v_{i+1}}$ returns $\False$. Then, again by \Cref{callaugmdfs}, there is no $M_{i}$-augmenting path in $G_{i+1}$ with endpoint $v_{i+1}$. Since $M_{i}$ is maximum in $G_{i}$, \Cref{BergeTheorem} implies that there is no $M_{i}$-augmenting path contained entirely in $G_{i}$. Thus, there is no $M_{i}$-augmenting path in $G_{i+1}$ at all, because any augmenting path in $G_{i+1}$ that is not contained in $G_{i}$ must involve the only new vertex of $V_{1}$, namely $v_{i+1}$. Therefore, by \Cref{BergeTheorem}, $M_{i}$ is already a maximum matching of $G_{i+1}$. Since the matching does not change in this case, we have
		\[
		M_{i+1} = M_{i},
		\]
		and so $M_{i+1}$ is a maximum matching of $G_{i+1}$.
	
		\medskip
		In both cases, $M_{i+1}$ is a maximum matching of $G_{i+1}$. This completes the induction.
	\end{proof}

	Before each search, we initialize the $\mathit{visited}$ array which takes $O(n)$ time. We call $\Call{DfsAugmentingPath}{}$ for each vertex $v \in V_{1}$ searching for an augmenting path. To find an augmenting path, we will visit each vertex and each edge at most once (similar to the classic DFS), so the total complexity is $O(nm)$ when $m = \Omega(n)$.

	\newpage 
	\subsection{Hopcroft-Karp Algorithm} Hopcroft and Karp provided a faster algorithm \cite{hopcroft1973n}, again based on finding augmenting paths, but in a smarter way. The algorithm runs in phases. In each phase, we find a maximal set of vertex-disjoint shortest $M$-augmenting paths and take the symmetric difference of the current matching $M$ with the union of these paths. The process stops when no augmenting path can be found. 

	Our implementation is based on the version of Shimon Even and Alon Itai, who made significant modifications to Dinic's algorithm for the maximum flow problem \cite{dinitz1970,dinitz2006}. As we will see at the end of this section, maximum flow and maximum bipartite matching are closely connected problems.

	The key idea of the algorithm is to efficiently find these paths and alternate their edges. To do that, we construct a new graph called the layered network. We describe this graph with an array called $\mathit{level}$, defined on the vertices of $V_{1}$. Initially, every free vertex of $V_{1}$ gets level $1$. Then, if a vertex $u \in V_{1}$ has level $i$, every vertex of $V_{1}$ that can be reached from $u$ by first taking an unmatched edge to a vertex of $V_{2}$ and then a matched edge back to  $V_{1}$ gets level $i+1$, provided it has not already received a level. The vertices are visited in Breadth-First Search (BFS) order, starting from all free vertices of $V_{1}$. In this way, $\mathit{level}[v]$ represents the minimum alternating distance of $v \in V_{1}$ from the set of free vertices of $V_{1}$ in the current phase. The edges in the layered network are directed according to the BFS levels, so the resulting graph is a directed acyclic graph (DAG).
	
	So, we can say that the algorithm has two essential steps. The first one is to build the layered network based on the current matching, and the second one is to find a maximal set of vertex-disjoint shortest augmenting paths in this graph and alternate their edges. We then construct the layered network again based on the updated matching and repeat the whole process.

	\begin{algorithm}[H]
	\caption{BFS Layered Network Construction}
	\label{layeredNetwork}
	\begin{algorithmic}[1]
	\Require Bipartite graph $G=(V_1 \cup V_2,E)$, arrays $\mathit{next}$, $\mathit{prev}$ represent the current matching
	\Ensure Array $\mathit{level}$ for the vertices of $V_{1}$ describes the layered network
	\Function{BfsLayeredNetwork}{\texttt{int} $\mathit{next}[]$, \texttt{int} $\mathit{prev}[]$, \texttt{int} $\mathit{level}[]$}
		\State $\mathit{treeDepth} \gets 0$;
		\State initialize empty queue $Q$;
		\ForAll{$u \in V_{1}$}
			\If{$\mathit{next}[u] = \emptyset$}
				\State $\mathit{level}[u] \gets 1$;
				\State $Q$.push($u$);
			\EndIf
		\EndFor
		\While{not $Q$.isEmpty()}
			\State $u \gets$ $Q$.pop();
			\ForAll{$x \in N(u)$}
				\If{$\mathit{prev}[x] = \emptyset$}
					\State $\mathit{treeDepth} \gets \mathit{level}[u]$;
					\State \textbf{continue};
				\EndIf
				\If{$\mathit{prev}[x] = u$}
					\State \textbf{continue};
				\EndIf
				\If{$\mathit{level}[\mathit{prev}[x]] = 0$}
					\State $\mathit{level}[\mathit{prev}[x]] \gets \mathit{level}[u] + 1$;
					\State $Q$.push($\mathit{prev}[x]$);
				\EndIf
			\EndFor
			\If{$\mathit{treeDepth} \neq 0$}
				\State \textbf{break};
			\EndIf
		\EndWhile
		\ForAll{$u \in V_{1}$}
			\If{$\mathit{level}[u] > \mathit{treeDepth}$}
				\State $\mathit{level}[u] \gets 0$;
			\EndIf
		\EndFor
		\State \Return $(\mathit{treeDepth} \neq 0)$;
	\EndFunction
	\end{algorithmic}
	\end{algorithm}

	The first time we encounter a free vertex in $V_{2}$, we determine the last useful level in the current phase and we store it in the variable $\mathit{treeDepth}$. From that, we can also determine the length of a shortest augmenting path in the current phase (which is $2\cdot \mathit{treeDepth} - 1$). We do not need to continue the BFS deeper than that level and the vertices that remain in the queue belong either to the same level or to the next one. The vertices of the same level may still be used in the searching step to find other shortest augmenting paths, since we have already assigned their correct level. On the other hand, vertices that have already been assigned level $\mathit{treeDepth} + 1$ correspond to longer paths, so we reset their level to $0$. 

	We define an array $\mathit{next}$ for every $v \in V_{1}$ such that $\mathit{next}[v] = u$ if and only if the edge $\{v,u\}$ belongs to the current matching; otherwise, $\mathit{next}[v] = \emptyset$. Similarly, for every $u \in V_{2}$, we define $\mathit{prev}[u] = v$ if and only if the edge $\{u,v\}$ belongs to the current matching; otherwise, $\mathit{prev}[u] = \emptyset$. Thus, the arrays $\mathit{next}$ and $\mathit{prev}$ represent the current matching and are updated whenever we find an augmenting path and alternate its edges.

	\begin{ttheorem}
		\Cref{layeredNetwork} correctly computes the array $\mathit{level}$ of the layered network of the current matching $M$. More precisely, if it returns $\False$, then no $M$-augmenting path exists in $G$. Otherwise, for every vertex $v \in V_{1}$, we have $\mathit{level}[v] \neq 0$ if and only if there exists an $M$-alternating path from a free vertex of $V_{1}$ to $v$. Moreover, if $\mathit{level}[v] \neq 0$, then the length of a shortest such path is $2 \cdot \mathit{level}[v] - 2$.
	\end{ttheorem}
	\begin{proof}
		For every free vertex $v \in V_{1}$, the algorithm sets $\mathit{level}[v] = 1$, and the corresponding alternating path has length $0$. Now suppose that a vertex $u \in V_{1}$ is popped from the queue and that the statement already holds for $u$. Let $x \in V_{2}$ be a neighbor of $u$.
	
		If $\mathit{prev}[x] = \emptyset$, then extending a shortest alternating path to $u$ by the edge $\{u,x\}$ gives an $M$-augmenting path of length $2 \cdot \mathit{level}[u] - 1$. If $\mathit{prev}[x] = u$, then $\{u,x\}$ is a matched edge and cannot be used to continue an alternating path. Otherwise, if $\mathit{prev}[x] = w \neq u$ and $\mathit{level}[w] = 0$, then by appending the unmatched edge $\{u,x\}$ and the matched edge $\{x,w\}$ to a shortest alternating path ending at $u$, we obtain an alternating path from a free vertex of $V_{1}$ to $w$ of length
		$(2 \cdot \mathit{level}[u] - 2) + 2 = 2 \cdot (\mathit{level}[u] + 1) - 2$.
		Hence, the algorithm correctly sets $\mathit{level}[w] = \mathit{level}[u] + 1$. Since vertices are processed in BFS order, this is the minimum possible alternating distance to $w$.
	
		Therefore, for every vertex $v \in V_{1}$ with $\mathit{level}[v] \neq 0$, the value $\mathit{level}[v]$ is exactly the level of $v$ in the layered network, and the length of a shortest alternating path from a free vertex of $V_{1}$ to $v$ is $2 \cdot \mathit{level}[v] - 2$.
	
		Finally, if the algorithm returns $\False$, then no free vertex of $V_{2}$ is reached during the BFS. Therefore, there is no $M$-augmenting path in $G$. Indeed, if such a path existed, then the vertex just before its free endpoint on a shortest such path would lie in the layered network, and the free vertex in $V_{2}$ would also be reached.
	\end{proof}
	
	\begin{ccor}
		If \Cref{layeredNetwork} returns $\True$, then the length of a shortest $M$-augmenting path is $2 \cdot \mathit{treeDepth} - 1$.
	\end{ccor}

	The searching step, \Cref{DfsHK}, is almost the same as \Cref{DfsAugmentingPath}, so we will omit the proof. This time, we move across the layered network based on the $\mathit{level}$ array. We also use an array $\mathit{ptr}$ for all vertices in $V_{1}$. This array holds for each vertex a counter that indicates the first neighbor that has not been checked yet. Hence, if we return to the same vertex in the same phase, we do not examine again the neighbors that have already returned $\False$. In particular, if $\mathit{ptr}[u]$ reaches the end of the adjacency list of $u$, then no augmenting path can be found through $u$ in the current phase. 

	We could of course combine the two $\mathit{if}$ statements into one.

	\begin{algorithm}[H]
	\caption{DFS Phase of Hopcroft-Karp}
	\label{DfsHK}
	\begin{algorithmic}[1]
	\Require Bipartite graph $G=(V_1 \cup V_2,E)$, vertex $u \in V_1$, arrays $\mathit{next}$, $\mathit{prev}$, $\mathit{level}$, $\mathit{ptr}$
	\Ensure Returns \True\ if a shortest augmenting path is found from $u$
	\Function{DfsHopcroftKarp}{\texttt{int} $u$, \texttt{int} $\mathit{next}[]$, \texttt{int} $\mathit{prev}[]$, \texttt{int} $\mathit{level}[]$, \texttt{int} $\mathit{ptr}[]$}
		\For{$\mathit{ptr}[u]$ \textbf{to} $|N(u)|-1$}
			\State $x \gets$ the $\mathit{ptr}[u]$-th neighbor of $u$;
			\If{$\mathit{prev}[x] = \emptyset$}
				\State $\mathit{prev}[x] \gets u$;
				\State $\mathit{next}[u] \gets x$;
				\State $\mathit{ptr}[u] \gets |N(u)|$;
				\State \Return \True;
			\EndIf
			\If{$\mathit{level}[\mathit{prev}[x]] = \mathit{level}[u] + 1$ \textbf{and} \Call{DfsHopcroftKarp}{$\mathit{prev}[x]$, $\mathit{next}$, $\mathit{prev}$, $\mathit{level}$, $\mathit{ptr}$}}
				\State $\mathit{prev}[x] \gets u$;
				\State $\mathit{next}[u] \gets x$;
				\State $\mathit{ptr}[u] \gets |N(u)|$;
				\State \Return \True;
			\EndIf
		\EndFor
		\State \Return \False;
	\EndFunction
	\end{algorithmic}
	\end{algorithm}

	\Cref{mainHK} and lines $9$-$21$ run the phases of the algorithm. In each phase, we call \Cref{layeredNetwork} (line $9$) to construct the layered network, find a maximal set of vertex-disjoint shortest augmenting paths in this graph by calling \Cref{DfsHK} for each free vertex of $V_{1}$ (lines $13$-$17$), and repeat the whole process. Note that we have to initialize the $\mathit{ptr}$ array to $0$ before starting the search, because all vertices will check their first neighbor first. We also have to initialize the $\mathit{level}$ array to zero before building the layered network. The set $\mathit{matching}$ contains the edges of the maximum matching.

	\begin{algorithm}[H]
	\caption{Hopcroft--Karp Algorithm}
	\label{mainHK}
	\begin{algorithmic}[1]
	\Require Bipartite graph $G=(V_1 \cup V_2,E)$
	\Ensure Array $\mathit{matching}$ contains the edges of the maximum matching
	\Function{HopcroftKarp}{\space}
		\ForAll{$u \in V_{1}$}
			\State $\mathit{next}[u] \gets \emptyset$;
			\State $\mathit{level}[u] \gets 0$;
		\EndFor
		\ForAll{$x \in V_{2}$}
			\State $\mathit{prev}[x] \gets \emptyset$;
		\EndFor
		\While{\Call{BfsLayeredNetwork}{$\mathit{next}$, $\mathit{prev}$, $\mathit{level}$}}
			\ForAll{$u \in V_{1}$}
				\State $\mathit{ptr}[u] \gets 0$;
			\EndFor
			\ForAll{$u \in V_{1}$}
				\If{$\mathit{next}[u] = \emptyset$}
					\State \Call{DfsHopcroftKarp}{$u$, $\mathit{next}$, $\mathit{prev}$, $\mathit{level}$, $\mathit{ptr}$};
				\EndIf
			\EndFor
			\ForAll{$u \in V_{1}$}
				\State $\mathit{level}[u] \gets 0$;
			\EndFor
		\EndWhile
		\State $\mathit{matching} \gets \emptyset$;
		\ForAll{$u \in V_{1}$}
			\If{$\mathit{next}[u] \neq \emptyset$}
				\State $\mathit{matching} \gets \mathit{matching} \cup \{\{u,\mathit{next}[u]\}\}$;
			\EndIf
		\EndFor
		\State \Return $\mathit{matching}$;
	\EndFunction
	\end{algorithmic}
	\end{algorithm}

	It is evident that constructing the layered network takes no more than $O(n + m)$. Moreover, lines $13$-$17$ take no more than $O(n + m)$ as each edge is examined at most once (with the help of $\mathit{ptr}$ array) and as a result when vertex returns $\False$, we are not going to process it again  in the current phase.

	\begin{llemma} \label{phaseHKComplexity}
		Each phase, that is calculating the maximal set of vertex-disjoint shortest $M$-augmenting paths and taking the symmetric difference with current matching $M$ takes no more than $O(n + m)$ time.
	\end{llemma}
	
	We shall show that we need at most $O(\sqrt{n})$ phases, but before that, we have to prove some important lemmas.
	\begin{llemma}\label{generalAPlemma}
			Let $M$ and $M^{'}$ be two matchings of a graph $G$, with $|M^{'}|>|M|$. Then the graph
			$M \bigtriangleup M^{'}$ contains at least $|M^{'}|-|M|$ vertex-disjoint $M$-augmenting paths.
	\end{llemma}
	\begin{proof}
		We follow the same logic as in \Cref{BergeTheorem}. We consider the graph $G = (V, M^{*})$ with $M^{*} = M \bigtriangleup M^{'}$. We can see that the graph contains components, each of which is an alternating path or an even-length cycle. Cycles have the same number of edges from $M$ and $M^{'}$, and the same holds for alternating paths of even length. Each component that represents an augmenting path has one more edge from one matching than from the other. In fact, every $M$-augmenting path has one more edge from $M^{'}$ than $M$. From $|M^{'}| > |M|$, we can see that we have more $M$-augmenting paths than $M^{'}$-augmenting paths, and there must be at least $|M^{'}| - |M|$ such paths. This completes the proof.
	\end{proof}

	The following is a special case of \Cref{generalAPlemma}.
	
	\begin{llemma} \label{specialCaseAPLemma}
		Given a matching $M$ and a maximum matching $M^{*}$, the graph contains $|M^{*}| - |M|$ vertex-disjoint $M$-augmenting paths.
	\end{llemma}

	\begin{llemma} \label{setRfromHKAlg}
		Let $P = \{P_{1}, P_{2}, \cdots, P_{t}\}$ be a maximal set of vertex-disjoint shortest $M$-augmenting paths with length $x$ obtained during a single phase of \Cref{mainHK} and $M^{'} = M \bigtriangleup (P_{1} \cup P_{2} \cup \cdots \cup P_{t}) = M \bigtriangleup P_{1} \bigtriangleup P_{2} \bigtriangleup \cdots \bigtriangleup P_{t}$ and let $Q$ be an $M^{'}$-augmenting path. The set $R = (P_{1} \cup P_{2} \cup \cdots \cup P_{t}) \bigtriangleup Q$ has at least $x(t + 1)$ edges.
	\end{llemma}
	\begin{proof}
		From $M^{'} = M \bigtriangleup (P_{1} \cup P_{2} \cup \cdots \cup P_{t})$, we have
		\[
			P_{1} \cup P_{2} \cup \cdots \cup P_{t} = M \bigtriangleup M^{'}
		\]
		That is,
		\[
			R= (M \bigtriangleup M^{'}) \bigtriangleup Q = M \bigtriangleup (M^{'} \bigtriangleup Q)
		\]
		Since $Q$ is an $M^{'}$-augmenting path, $M^{'} \bigtriangleup Q$ (which is obviously a valid matching) has size of $|M^{'}| + 1 = |M| + t + 1$ (plus $t + 1$ because it will get $t + 1$ more edges from alternating the paths of $P$ and the path $Q$). By \Cref{generalAPlemma}, there is at least $|M^{'} \bigtriangleup Q| - |M| = t + 1$ $M$-augmenting paths. Because every $M$-augmenting path has length at least $x$, it follows that $R$ has at least $x(t + 1)$ edges.
	\end{proof}

	\begin{llemma} \label{lengthAugmInHK}
		The length of the shortest augmenting path (if exists) increases in every phase.
	\end{llemma}
	\begin{proof}
		Let’s assume that the current matching is $M$ and denote by $P = \{P_{1}, P_{2}, \cdots, P_{t}\}$ the maximal set of vertex-disjoint shortest $M$-augmenting paths  of length $x$ in one phase of \Cref{mainHK}. Moreover, suppose that we take $M^{'} = M \bigtriangleup (P_{1} \cup P_{2} \cup \cdots \cup P_{t})$ (the matching that we get at the end of phase) and let $Q$ be an $M^{'}$-augmenting path. Obviously, $Q$ has a common vertex $v$ with at least one path from $P$, otherwise, $Q$ would also be an $M$-augmenting path and either $|Q| > x$ (in this case we are done) or it would contradict the maximality of the set. Let $R = (P_{1} \cup P_{2} \cup \cdots \cup P_{t}) \bigtriangleup Q$. From \Cref{setRfromHKAlg}, $R$ has at least $x(t+1)$ edges. Let $P_{i} \in P$ such that $v \in P_{i}$. We observe that $v$ is incident with a matched edge in $M^{'}$ because at the end of the phase we alternate the edges of each path in $P$. The endpoints of $Q$ do not belong to $M^{'}$ because they are free, so it is guaranteed that $v$ is an internal vertex of $Q$ and therefore it is also incident with a matched edge in $M^{'}$. Obviously, it's impossible for $v$ to be incident with two different matched edges from $M^{'}$, so $P_{i}$ and $Q$ have at least one edge from $M^{'}$ in common. It follows that
		\[
			xt + x \leq |R| \leq |P_{1} \cup P_{2} \cup \cdots \cup P_{t} \cup Q| \leq xt + |Q| - 1
		\]
		and hence $x + 1 \leq |Q|$.
	\end{proof}
	
	\begin{llemma} \label{HKTotalPhases}
		\Cref{mainHK} performs at most $O(\sqrt{n})$ phases.
	\end{llemma}
	\begin{proof}
		Assume that we have already performed $\sqrt{n}$ phases and the current matching is $M$. From \Cref{specialCaseAPLemma}, we know that there exist at least $|M^{*}| - |M|$ vertex-disjoint $M$-augmenting paths for a maximum matching $M^{*}$.
		From \Cref{lengthAugmInHK} all these augmenting paths will have length at least $\sqrt{n}$, so there cannot be more than $\sqrt{n}$ (we would need more than $n$ vertices) of them, which means that $|M^{*}| - |M| \leq \sqrt{n}$. It follows from this that we can't perform more than $\sqrt{n}$ phases from that point. We conclude that the total phases can't be more than $2\sqrt{n} = O(\sqrt{n})$.
	\end{proof}
	
	From \Cref{phaseHKComplexity} and \Cref{HKTotalPhases} we get the complexity of Hopcroft-Karp algorithm.
	
	\begin{ttheorem}
		\Cref{mainHK} returns a maximum matching in $O((n+m)\sqrt{n})$ time.
	\end{ttheorem}

	\paragraph{Maximum Bipartite Matching from Max-Flows.} We can reduce the bipartite maximum matching problem to the maximum flow problem by adding two extra nodes to the initial graph. The first vertex is called the source and will point to all vertices in $V_{1}$ with directed edges, and the second vertex is called the sink, with all vertices from $V_{2}$ pointing to it. Moreover, all the edges of the initial graph will turn into directed edges, pointing to $V_{2}$ from a vertex of $V_{1}$. Assuming capacities of one for each edge (so there exists an integral maximum flow, that is every edge will have flow of $0$ or $1$), the maximum flow from source to sink is equal to the maximum bipartite matching. Actually, this is easy to see, because all paths that carry flow from the source to the sink should be edge-disjoint and use exactly one edge from $V_{1}$ to $V_{2}$, while the flow passing through each vertex of these paths is exactly one (which means that no vertex is repeated). We can get a maximum flow in the resulting graph from a maximum matching in the initial graph by just taking all the edges of matching and picking the edges from the source to the corresponding $V_{1}$ vertices, and the edges from the corresponding $V_{2}$ vertices to the sink.
	
	Consequently, someone could make the above reduction and use a famous flow algorithm, like Dinic \cite{dinitz1970} to solve the maximum bipartite problem with $O(n^{2}m)$. It turns out, that using some kind of the arguments we talked before, Dinic's algorithm will perform with the same complexity as Hopcroft-Karp algorithm.

	\paragraph{Recent Research.} Maximum flow is well-known problem in computer science and has been studied extensively over the years. Finding faster algorithms for the maximum flow problem, and  especially for the minimum-cost flow problem (to which maximum flow can be reduced), could lead to breakthroughs in many areas. For a long time, algorithms based primarily on combinatorial methods were far from the almost-linear-time bounds achieved by more recent continuous techniques. In 2023, a deterministic $m^{1+o(1)}$-time algorithm for exact maximum flow and minimum-cost flow on directed graphs with polynomially bounded integral demands, costs, and capacities was discovered \cite{brand2023deterministic}. This line of work also implies an $m^{1+o(1)}$-time algorithm for the maximum bipartite matching problem. On the other hand, randomized combinatorial algorithms were later obtained independently for exact maximum flow \cite{maxFlowBernstein} and for maximum bipartite matching \cite{MBMChuzhoy}.

\section{The Stable Marriage Problem}\label{sec:stable-marriage}

	Assume that we are given a set of $n$ men $\{m_{1}, m_{2}, \dots, m_{n}\}$ and $n$ women $\{w_{1}, w_{2}, \dots, w_{n}\}$, where each man has a strict preference ranking over all $n$ women, and each woman also has a strict preference ranking over all $n$ men. We say that a $\mathit{matching}$ is a set of unordered pairs consisting of a man and a woman (similarly to the previous section, where we considered the undirected edges of a bipartite graph), where each man and each woman appears in at most one pair. A $\mathit{marriage}$ is a perfect matching between men and women, meaning that every man and every woman is matched exactly once. A marriage is $\mathit{unstable}$ if there exists a pair $\{m_{i}, w_{j}\}$ that does not belong to the matching such that $m_{i}$ prefers $w_{j}$ over his actual partner, and $w_{j}$ prefers $m_{i}$ over her actual partner. We call such a pair a $\mathit{blocking}$ $\mathit{pair}$. Otherwise, we say that it is $\mathit{stable}$.

	The following example shows a stable marriage.
	\begin{eexample}
		Consider an instance of four men
		\[
		\{m_{1},m_{2},m_{3},m_{4}\}
		\]
		and four women
		\[
		\{w_{1},w_{2},w_{3},w_{4}\}.
		\]
		
		The preference lists of the men are given by
		\[
		\begin{array}{c|cccc}
			\text{man} & 1^{\text{st}} & 2^{\text{nd}} & 3^{\text{rd}} & 4^{\text{th}} \\ \hline
			m_{1} & w_{1} & w_{2} & w_{3} & w_{4} \\
			m_{2} & w_{2} & w_{1} & w_{3} & w_{4} \\
			m_{3} & w_{3} & w_{4} & w_{1} & w_{2} \\
			m_{4} & w_{4} & w_{3} & w_{1} & w_{2}
		\end{array}
		\]
		and the preference lists of the women are
		\[
		\begin{array}{c|cccc}
			\text{woman} & 1^{\text{st}} & 2^{\text{nd}} & 3^{\text{rd}} & 4^{\text{th}} \\ \hline
			w_{1} & m_{2} & m_{1} & m_{3} & m_{4} \\
			w_{2} & m_{1} & m_{2} & m_{3} & m_{4} \\
			w_{3} & m_{4} & m_{3} & m_{1} & m_{2} \\
			w_{4} & m_{3} & m_{4} & m_{1} & m_{2}
		\end{array}
		\]
		Now consider the matching
		\[
		M=\{\{m_{1},w_{2}\},\{m_{2},w_{1}\},\{m_{3},w_{4}\},\{m_{4},w_{3}\}\}.
		\]
		
		We can see that $M$ is stable. Indeed, each woman is matched to her first choice:
		\[
		w_{1} \text{ is matched with } m_{2},\quad
		w_{2} \text{ is matched with } m_{1},\quad
		w_{3} \text{ is matched with } m_{4},\quad
		w_{4} \text{ is matched with } m_{3}.
		\]
		Hence, no woman prefers any other man to her assigned partner. Therefore, no blocking pair can exist, since a blocking pair would require both to prefer each other over their current partners. Consequently, $M$ is a stable matching.
		Moreover, this stable matching is not unique, since
		\[
		M^{'}=\{\{m_{1},w_{1}\},\{m_{2},w_{2}\},\{m_{3},w_{3}\},\{m_{4},w_{4}\}\}
		\]
		is also stable.
	\end{eexample}

		\[
		\{m_{1},m_{2},m_{3},m_{4}\}

		and four women

		\[
		\begin{array}{c|cccc}
			\text{man} & 1^{\text{st}} & 2^{\text{nd}} & 3^{\text{rd}} & 4^{\text{th}} \\ \hline
			m_{1} & w_{1} & w_{2} & w_{3} & w_{4} \\
			m_{2} & w_{2} & w_{3} & w_{1} & w_{4} \\
			m_{3} & w_{2} & w_{1} & w_{4} & w_{3} \\
			m_{4} & w_{3} & w_{4} & w_{1} & w_{2}
		\end{array}
		\]
		and the preference lists of the women are
		\[
		\begin{array}{c|cccc}
			\text{woman} & 1^{\text{st}} & 2^{\text{nd}} & 3^{\text{rd}} & 4^{\text{th}} \\ \hline
			w_{1} & m_{3} & m_{1} & m_{2} & m_{4} \\
			w_{2} & m_{1} & m_{2} & m_{3} & m_{4} \\
			w_{3} & m_{2} & m_{4} & m_{1} & m_{3} \\
			w_{4} & m_{4} & m_{3} & m_{1} & m_{2}
		\end{array}
		\]
		
		Now consider the matching
		\[
		M=\{\{m_{1},w_{1}\},\{m_{2},w_{2}\},\{m_{3},w_{4}\},\{m_{4},w_{3}\}\}.
		\]
		
		We claim that $M$ is not stable. Indeed, the pair $\{m_{3}, w_{1}\}$ is a blocking pair, since
		$ m_{3} \text{ prefers } w_{1} \text{ to } w_{4}, $
		while
		$ w_{1} \text{ prefers } m_{3} \text{ to } m_{1}.$
		Thus, both $m_{3}$ and $w_{1}$ prefer each other to their assigned partners under $M$. Hence, $M$ admits a blocking pair and therefore it is not a stable matching.
	\end{eexample}

	Gale and Shapley \cite{Gale01011962} provided an algorithm that always outputs a stable marriage. The algorithm is quite simple. In each iteration of the algorithm, we try to match a man who is not matched to any woman by proposing to the woman he currently prefers most, and the woman accepts the best proposal she receives. If a man is matched with a woman and she later receives a better proposal, then she will leave her current partner and accept that proposal. The man will become unmatched again, and we will try to match him again in a later iteration, starting from the next woman in his preference list.

	\begin{algorithm}[H]
	\caption{Gale--Shapley Algorithm}
	\label{stableMarriageAlgorithm}
	\begin{algorithmic}[1]
		\Require Preference arrays $\mathit{men}$, $\mathit{women}$ and their size $n$
		\Ensure Array $\mathit{manPartner}$ contains a stable matching
		\Function{StableMarriage}{\texttt{int} $n$, \texttt{int} $\mathit{men}[][]$, \texttt{int} $\mathit{women}[][]$}
		    \State initialize empty queue $Q$;
			\For{$i \gets 0$ \textbf{to} $n - 1$}
				\State $\mathit{ptr}[i] \gets 0$;
		        \State $\mathit{womanPartner}[i] \gets \emptyset$;
		        \State $\mathit{manPartner}[i] \gets \emptyset$;
		        \State $Q$.push($i$);
			\EndFor
			\For{$i \gets 0$ \textbf{to} $n-1$}
			    \For{$j \gets 0$ \textbf{to} $n-1$}
			        \State $\mathit{rank}[i][\mathit{women}[i][j]] \gets j$;
			    \EndFor
			\EndFor
		    \While{not $Q$.isEmpty()}
		        \State $m \gets$ $Q$.pop();
		        \While{$\mathit{manPartner}[m] = \emptyset$}
		            \State $w \gets \mathit{men}[m][\mathit{ptr}[m]]$;
		            \State $\mathit{ptr}[m]++$;
		            \If{$\mathit{womanPartner}[w] = \emptyset$}
		                \State $\mathit{womanPartner}[w] \gets m$;
		                \State $\mathit{manPartner}[m] \gets w$;
		            \Else
		                \If{$\mathit{rank}[w][m] < \mathit{rank}[w][\mathit{womanPartner}[w]]$}
		                    \State $\mathit{manPartner}[m] \gets w$;
		                    \State $Q$.push($\mathit{womanPartner}[w]$);
		                    \State $\mathit{manPartner}[\mathit{womanPartner}[w]] \gets \emptyset$;
		                    \State $\mathit{womanPartner}[w] \gets m$;
		                \EndIf
		            \EndIf
		        \EndWhile
		    \EndWhile
		    \State \Return $\mathit{manPartner}$;
		\EndFunction
	\end{algorithmic}
	\end{algorithm}

	The input of the algorithm is the size $n$ and the preference lists $\mathit{women}$ and $\mathit{men}$. $\mathit{women}[i]$ is the preference list of woman $i$ and $\mathit{men}[j]$ is the preference list of man $j$. Arrays $\mathit{womanPartner}$ and $\mathit{manPartner}$ represent the current matching. We will use two extra arrays that will help us see if a proposal can be made and whether it benefits us. Array $\mathit{ptr}$ will store, for a man $i$, the most highly preferred woman that he has not proposed to yet. Using this array, we will be able to know the answer immediately. Array $\mathit{rank}$ will help us determine, for a woman, whether she prefers the current matched man or the proposing one in $O(1)$. Specifically, for a woman $i$, we store at $\mathit{rank}[i][j]$ the position of the man $j$ in her preference list. This (lines $9$-$13$), requires $O(n^{2})$ preprocessing. In lines $14-31$ we perform the proposals. 
	
	See that if a woman receives a proposal, then she will either accept it or stay with her current partner. This leads to the following lemma.
	\begin{llemma} \label{GaleWomanMatching}
		After a woman receives a match, she never becomes unmatched again.
	\end{llemma}

	Note that it is not necessary to check whether $\mathit{ptr}[m]$ becomes greater than $n - 1$, which would mean that we popped a man who is unmatched, but all the women are already matched.

	\begin{llemma}\label{GaleHaltsAndMarriage}
		\Cref{stableMarriageAlgorithm} always halts and produces a marriage.
	\end{llemma}
	\begin{proof}
		Assume that a man gets popped in line $15$, which means that he is unmatched, but has already proposed to all women. Then every woman has rejected him for some other man and, by \Cref{GaleWomanMatching}, all women are matched. This is a contradiction, because this would mean that a man appears in more than one match, so necessarily an unmatched woman exists. Consequently, every time we pop a man from the queue, there will always exist a woman who is unmatched. Since each man proposes to each woman at most once, there exist at most $n^{2}$ proposals, so the algorithm halts. Finally, when the algorithm halts, no man is unmatched, hence the output is a marriage.
	\end{proof}

	Now we are going to prove the output of the algorithm is stable.

	\begin{llemma}
	\Cref{stableMarriageAlgorithm} produces a stable marriage.
	\end{llemma}
	\begin{proof}
		By \Cref{GaleHaltsAndMarriage}, we know that it produces a marriage. Assume, to the contrary, that the output is not stable, which means that a blocking pair $(m_{i}, w_{j})$ exists. Because $(m_{i}, w_{j})$ does not belong to the matching, two cases are possible.
	
		In the first case, the man $m_{i}$ proposed to $w_{j}$ and she rejected him (immediately or accepted him temporarily and later left him for a better proposal). This means that $w_{j}$ prefers the man from the matching. A contradiction.
	
		In the second case, the man $m_{i}$ never proposed to $w_{j}$, which means that he matched with a woman who is higher on his preference list. Also a contradiction.
	\end{proof}

	As we perform $O(n^{2})$ proposals and we can decide whether to accept a proposal or not in $O(1)$ time (using $O(n^{2})$ preprocessing), the total time complexity is $O(n^{2})$.

	\begin{ttheorem}
		\Cref{stableMarriageAlgorithm} computes a stable marriage in $O(n^{2})$ time.
	\end{ttheorem}

	\begin{ddef}
		\Cref{stableMarriageAlgorithm} operates as a men-proposing algorithm since a man first proposes to his most preferred woman, leaving the woman to accept the best proposal available to her.
	\end{ddef}

	\begin{ttheorem}\label{stableMarriage-man-optimal}
		The men-proposing \Cref{stableMarriageAlgorithm} is man-optimal, as every man is matched to the best partner he could possibly obtain in any stable marriage.
	\end{ttheorem}
	\begin{proof}
		Suppose, for the sake of contradiction, that it is not man-optimal, and that the output of \Cref{stableMarriageAlgorithm} is a marriage $M$. This means that there exist some rejections in our algorithm such that the corresponding pairs are matched in another stable marriage $M^{'}$. From those rejections, fix the first one. That is, a man $m_{i}$ got rejected by woman $w_{j}$ because $w_{j}$ prefers $m_{z}$ to $m_{i}$, and another stable marriage $M^{'}$ exists, where $m_{i}$ is matched with $w_{j}$, i.e., $\{m_{i}, w_{j}\} \in M^{'}$, and $m_{z}$ is matched with $w_{k}$, i.e., $\{m_{z}, w_{k}\} \in M^{'}$. If $m_{z}$ prefers $w_{j}$ to $w_{k}$, then $\{m_{z}, w_{j}\}$ is a blocking pair in $M^{'}$, which leads to a contradiction. If $m_{z}$ prefers $w_{k}$ to $w_{j}$, then it would be impossible for the first rejection to be that of $m_{i}$ by $w_{j}$, because it would mean that $w_{j}$ is already matched with $m_{z}$, implying that $m_{z}$ was rejected by $w_{k}$ in some previous iteration. This also leads to a contradiction.
	\end{proof}
	
	Although the output of the algorithm is man-optimal, it is the worst matching for women.	

	\begin{ttheorem}
		The men-proposing \Cref{stableMarriageAlgorithm} is female-pessimal, meaning every woman is matched with the least preferred valid partner she could have in any stable matching.
	\end{ttheorem}
	\begin{proof}
		Similar to the previous proof, assume to the contrary that woman $w_{j}$ is matched with man $m_{i}$ in the marriage output $M$ of \Cref{stableMarriageAlgorithm} and that there exists another stable marriage $M^{'}$ such that $w_{j}$ is matched with a man $m_{z}$ whom she prefers less than $m_{i}$ and $m_{i}$ is matched with a woman $w_{k}$. Because $M$ is man-optimal by \Cref{stableMarriage-man-optimal}, $m_{i}$ prefers $w_{j}$ to $w_{k}$. The pair $\{m_{i}, w_{j}\}$ is a blocking pair for $M^{'}$. This is a contradiction, since $M^{'}$ is stable.
	\end{proof}

	\paragraph{Further Variants of the Model.} The Gale and Shapley algorithm focuses on a one-to-one matching model, which means that each element from one set can be matched to exactly one element from the other set. Also, the sizes of the sets and the preference lists are the same. These assumptions are actually rare. In real-life scenarios, we may have many-to-one or even many-to-many assignments, incomplete lists, and preferences with ties. Additionally, stability is just one of many criteria used to evaluate the quality of a matching. In a later chapter, we will study some of these extended scenarios.


\chapter{Polyhedral Approaches to Matching Problems}

\section{Preliminaries}
	
	There exist many excellent references on linear programming and polyhedral combinatorics. This section is based mainly on \cite{matousek2007understanding} and \cite{schrijver2003volA}.
	
	Let $C$ be any subset of $\mathbb{R}^{n}$. We say that $C$ is \emph{convex} if for every two points $u, v \in C$ and for every $\lambda \in [0, 1]$, $u + \lambda d$ belongs to $C$, where $d = v - u$. In other words, we say that $C$ is convex if for every $u, v \in C$, it also contains the line segment between $u$ and $v$. It is easy to see that the intersection of convex sets is convex. 
	
	Let $S \subset \mathbb{R}^{n}$ be a set. The \emph{convex hull} of $S$, denoted by $\mathit{conv(S)}$, is the intersection of all the convex sets containing $S$. Expressed differently, it is the smallest convex set containing $S$. It is often more useful to describe the convex hull in terms of convex combinations.
	
	Let $v_{1}, \ldots, v_{k} \in \mathbb{R}^{n}$ and $\lambda_{1}, \ldots, \lambda_{k}$ be non-negative reals such that $\lambda_{1} + \ldots + \lambda_{k} = 1$. Then, $\lambda_{1}v_{1} + \ldots + \lambda_{k}v_{k}$ is called a \emph{convex combination} of $v_{1}, \ldots, v_{k}$. Geometrically, convex combinations can be viewed as taking the line segments between the given points (by setting all coefficients to zero except those corresponding to two points) and then generating all points contained in the resulting shape as more coefficients are allowed to be non-zero. For two points, this generates the entire line segment connecting them, and for three \emph{non-collinear} points, it generates the whole triangle (including its boundary). The set of all such points forms a convex set, called the convex hull of the given set. Therefore, $\operatorname{conv}(S) = \{\sum_{i = 1}^{k} \lambda_{i} v_{i} : k \in \mathbb{N}, v_{i} \in S, \lambda_{i} \geq 0, \sum_{i = 1}^{k} \lambda_{i} = 1 \}$, which is equivalent to the previous definition.
	
	A set $S \subseteq \mathbb{R}^{n}$ is an \emph{affine subspace} of $\mathbb{R}^{n}$ if $S = p + V = \{p + v : v \in V\}$ for some $p \in \mathbb{R}^{n}$ and some linear subspace $V$ of $\mathbb{R}^{n}$. In other words, it is a linear subspace that has been shifted by a fixed vector. If $p \in V$, then the subspace is simply a linear subspace. 
	
	Recall the definition of a convex combination, but let $\lambda_{i} \in \mathbb{R}$ instead of $\lambda_{i} \in [0, 1]$. For two points, the result is the line passing through these two points. This line is formed by the affine combinations of these points (and it does not need to pass through the origin). In general, given $v_{1}, \ldots, v_{k} \in \mathbb{R}^{n}$ and $\lambda_{1}, \ldots, \lambda_{k} \in \mathbb{R}$ such that $\lambda_{1} + \ldots + \lambda_{k} = 1$, the sum $\lambda_{1}v_{1} + \ldots + \lambda_{k}v_{k}$ is called an \emph{affine combination} of $v_{1}, \ldots, v_{k}$. 
	
	The dimension of an affine subspace $S$, denoted by $\operatorname{dim}(S)$, is defined to be $\operatorname{dim}(V)$. Using affine combinations, we can generate a line, a plane, or a \emph{hyperplane}, which is an affine subspace of dimension $n - 1$. Similarly to the definition of a convex hull, given a set $S \subseteq \mathbb{R}^{n}$, the \emph{affine hull} of $S$ ($\operatorname{aff}(S)$)  is the intersection of all affine subspaces containing $S$, or equivalently, the set of all possible affine combinations of a finite number of elements of $S$. 
	
	We are also interested in knowing which points contribute to  ``extending" the affine hull (i.e., increasing its dimension). For example, in $\mathbb{R}^{2}$, the points $(1, 0)$, $(0, 1)$, and $(1, 1)$ are affinely independent because the first two define a line, and by adding $(1, 1)$, we extend the affine hull to all of $\mathbb{R}^{2}$. We say that the points $v_{1}, \ldots, v_{k} \in \mathbb{R}^{n}$ are \emph{affinely independent} if none of them can be written as an affine combination of the remaining points. It can be proved that $v_{1}, \ldots, v_{k} \in \mathbb{R}^{n}$ are affinely independent if and only if the vectors $v_{2} - v_{1}, \ldots, v_{k} - v_{1}$ are linearly independent.
	
	A hyperplane in $\mathbb{R}^{n}$ describes all the solutions $x \in \mathbb{R}^{n}$ of a single linear equation of the form $a_{1}x_{1} + a_{2}x_{2} + \ldots + a_{n}x_{n} = b$ where at least one $a_{i}$ is not zero and $b \in \mathbb{R}$. We can also express it using two inequalities $a_{1}x_{1} + a_{2}x_{2} + \ldots + a_{n}x_{n} \leq b$ and $a_{1}x_{1} + a_{2}x_{2} + \ldots + a_{n}x_{n} \geq b$. These inequalities are called \emph{half-spaces} (and more specifically \emph{closed} half-spaces because they contain their boundary). 
	
	A \emph{polyhedron} $P \subseteq \mathbb{R}^{n}$ is the intersection of a finite number of halfspaces. This means that we could write $P = \{x \in \mathbb{R}^{n} : Ax \leq b\}$ where $A \in \mathbb{R}^{m \times n}$ and $b \in \mathbb{R}^{m}$. It is easy to see that polyhedra are convex because halfspaces are convex. We call $z$ an \emph{extreme point} (or \emph{vertex}) of $P$ if $z \in P$ and there do not exist distinct $x,y \in P$ and $\lambda \in (0,1)$ such that $z = (1 - \lambda)x + \lambda y$ (which means that $z$ is not an internal point of any segment from $x$ to $y$ such that $x,y \in P$). The \emph{dimension} of a polyhedron $P$, denoted by $\operatorname{dim}(P)$, is the minimum dimension of an affine subspace containing $P$.
	
	Let $P = \{x \in \mathbb{R}^{n} : Ax \leq b\}$ and denote $a_i^T$ to be the $i$-th row of $A$. For a point $x^{*} \in P$, we say that the inequality $a_i^Tx \leq b_i$ is \emph{active} at $x^{*}$ if $a_i^Tx^{*} = b_i$. Let $A^{=}x \leq b^{=}$ be the subsystem of $Ax \leq b$ active at $x^{*}$. A point $x^{*} \in P$ is an extreme point of $P$ if and only if the active constraint vectors at $x^{*}$ contain $n$ linearly independent rows, i.e., $\operatorname{rank}(A^{=}) = n. $
	In general, if a polyhedron is described by both equalities and inequalities,
	$ P = \{x \in \mathbb{R}^{n} : Dx = d,\ Ax \leq b\}$, then $x^{*} \in P$ is an extreme point of $P$ if and only if
	$
	\operatorname{rank}
	\begin{bmatrix}
		D \\
		A^{=}
	\end{bmatrix}
	= n
	$.
	
	An inequality $a^Tx \leq b$ is called \emph{valid} for $P$ if it is satisfied by every point of $P$, that is, if $a^Tx \leq b$ for all $x \in P$. A point $x\in P$ is said to be \emph{tight} for the valid inequality
	$a^Tx\leq b$ if it satisfies the inequality with equality, that is, if
	$a^Tx=b$. The set
	$F = \{x \in P : a^Tx = b\}$
	is called the \emph{face} of $P$ induced by this valid inequality. A face $F$ of $P$ is called a \emph{proper face} if
	$F\ne\varnothing$ and $F\ne P$.
	A face $F$ of $P$ is called a \emph{facet} if $\operatorname{dim}(F) = \operatorname{dim}(P) - 1.$
	In this case, we say that the inequality $a^Tx \leq b$ is \emph{facet-defining} for $P$. Equivalently, if $d = \operatorname{dim}(P)$ and the inequality is not satisfied with equality by every point of $P$, then it is facet-defining if and only if its equality set contains $d$ affinely independent points of $P$.
	
	A polyhedron $P \subseteq \mathbb{R}^{n}$ is called a \emph{polytope} if it is bounded (in other words there exists $M > 0$ such that $\|x\| < M$, $\forall x \in P$, where $\|\|$ is the euclidean norm). A polytope has a finite number of extreme points and every other point of that polytope can be expressed as a convex combination of its extreme points. In fact, if $C$ is the set of the extreme points of $P$, we can describe it with the convex hull of $C$, which means that $P = \operatorname{conv}(C)$. Hence, there are two representations of a polytope $P$. The first one is by defining the linear inequalities $Ax \leq b$, which is called the \emph{H-description} (or \emph{linear description}) and the second one by its vertices, which is called the \emph{V-description}.
	
	A polyhedron $P \subseteq \mathbb{R}^{n}$ with at least one vertex is called \emph{integral} if all of its vertices are integral. In particular, a polytope is integral if and only if
	$P = \operatorname{conv}(P \cap \mathbb{Z}^{n})$.
	
	Let $c \in \mathbb{R}^{n}$. In linear programming (LP) we are interested to maximize a function $c^{T}x$ (which is often called an \emph{objective function}) over a polyhedron. This is a linear optimization problem, which we call it a \emph{primal problem}. The \emph{constraints} of that problem are the linear description of it. In this thesis, we will mostly use maximization problems with nonnegative variables. Unless stated otherwise, the variables of a linear program are assumed to be real-valued. Hence, the primal problem can be expressed as
	\begin{equation} \label{3.1}
		\begin{aligned}
			\max \ & c^T x \\
			\text{s.t.} \ & Ax \leq b \\
			& x \geq 0
		\end{aligned}
	\end{equation}
	
	Any vector $x \in \mathbb{R}^n$ satisfying all constraints is called a \emph{feasible solution}. The set of all feasible solutions is called the \emph{feasible region} and in the case of a linear program, this region is a polyhedron. Any feasible solution that achieves the maximum possible value of the objective function is called an \emph{optimal solution}. There can be multiple optimal solutions, or none at all. If the objective function can attain arbitrarily large values, we say that the LP is \emph{unbounded}. Such a problem can be solved using known algorithms that are polynomial in the input size, for example, the ellipsoid method.
	
	We also recall the basic notion of linear programming duality. Consider the primal linear program of \eqref{3.1}
	where $A \in \mathbb{R}^{m \times n}$, $b \in \mathbb{R}^{m}$ and $c \in \mathbb{R}^{n}$. The corresponding \emph{dual problem} is
	\[
	\begin{aligned}
		\min \quad & b^Ty \\
		\text{s.t.} \quad & A^Ty \geq c, \\
		& y \geq 0.
	\end{aligned}
	\]
	The variables $x$ are called the \emph{primal variables}, while the variables $y$ are called the \emph{dual variables}. A vector satisfying the constraints of the primal problem is called a \emph{primal feasible solution}, and a vector satisfying the constraints of the dual problem is called a \emph{dual feasible solution}.
	
	The weak duality theorem states that, for every primal feasible solution $x$ and every dual feasible solution $y$, we have
	\[
	c^Tx \leq b^Ty.
	\]
	Therefore, the value of any dual feasible solution gives an upper bound on the value of any primal feasible solution.
	
	The strong duality theorem states that, if the primal problem has an optimal solution and its optimal value is finite, then the dual problem also has an optimal solution and the two optimal values are equal.
	
	We recall two standard facts relating linear programs and vertices of polyhedra. 
	
	\begin{pprop} \label{hyperplane-th}
		Let $P \subseteq \mathbb{R}^{n}$ be a polyhedron, and let $v \in P$. If $v$ is a vertex of $P$, then there exists a nonzero vector $c\in \mathbb{R}^{n}$ such that \[ c^Tv > c^Ty \] for every $y\in P\setminus\{v\}$. 
	\end{pprop}
	
	\begin{ttheorem} (Fundamental theorem of linear programming)
		Let $P \subseteq \mathbb{R}^{n}$ be a polyhedron. If the linear program \[ \max\{c^Tx : x\in P\} \] has an optimal solution and $P$ has at least one vertex, then it has an optimal solution that is a vertex of $P$. 
	\end{ttheorem}
	
	Consider a linear program $ \max \{c^Tx : Ax = b,\ x \geq 0\}$ (which is often called \emph{standard form}), where $A \in \mathbb{R}^{m \times n}$ has rank $m$. A set $B \subseteq \{1, \ldots, n\}$ with $|B| = m$ is called a \emph{basis} if the submatrix $A_B$ consisting of the columns of $A$ indexed by $B$ is nonsingular. The variables indexed by $B$ are called \emph{basic variables}, while the remaining variables are called \emph{nonbasic variables}. Setting the nonbasic variables equal to $0$ and solving $A_Bx_B = b$ gives the associated \emph{basic solution}, namely
	\[
	x_B = A_B^{-1}b, \qquad x_N = 0.
	\]
	If this solution also satisfies $x_B \geq 0$, then it is called a \emph{basic feasible solution}.
	
	For linear programs in standard form, the basic feasible solutions are exactly the extreme points of the feasible polyhedron. Therefore, if such a linear program has an optimal solution, then it has an optimal basic feasible solution.
	
	If we consider the LP problem but restrict $x \in \mathbb{Z}^{n}_{+}$, it becomes an \emph{integer program} (IP). Unlike LP, this problem is difficult, i.e., it is known to be NP-hard. However, if the feasible region of the LP relaxation is integral, then we can solve the LP instead of the IP and obtain an integer optimal solution. The problem is still difficult if the size of the linear description is exponential in $n$ or $m$. One way to address this issue is by solving the \emph{separation} problem, in which, for a given point $x \in \mathbb{R}^{n}_{+}$, we decide whether it violates any of the inequalities of $Ax \leq b$ and return one such inequality (we will use this technique in the last chapter).
	
	A matrix $A$ is \emph{totally unimodular} if every square submatrix of $A$ has determinant equal to $0$, $1$ or $-1$. We will prove the following lemma.
	\begin{llemma}
		Let $A$ be a totally unimodular matrix and let $A^{'}$ be the matrix obtained from $A$ by appending a unit vector \(e_i\) as a new column. Then $A^{'}$ is totally unimodular.
	\end{llemma}
	\begin{proof}
		Let $B$ be an arbitrary square submatrix of $A'$. If $B$ does not contain the appended column $e_i$, then $B$ is a square submatrix of $A$, and therefore $\det(B)\in\{-1,0,1\}$.
		
		Suppose now that $B$ contains the appended column. The restriction of $e_i$ to the rows of $B$ is either the zero vector or a unit vector. In the first case, $B$ has a zero column, so $\det(B)=0$. In the second case, expanding along this column gives
		\[
		\det(B)=\pm \det(C),
		\]
		where $C$ is a square submatrix of $A$. Since $A$ is totally unimodular, $\det(C)\in\{-1,0,1\}$, and hence $\det(B)\in\{-1,0,1\}$.
		
		Thus every square submatrix of $A'$ has determinant in $\{-1,0,1\}$, so $A'$ is totally unimodular.
	\end{proof}
	
	An \emph{LP relaxation} of an IP is obtained by removing the integrality constraints on the variables and allowing them to take arbitrary real values within the feasible region.
	We now show how total unimodularity can be used to solve IP via LP relaxation, following the approach of \cite[p.~145]{matousek2007understanding}.
	
	\begin{llemma}
		Let
		$\max \{c^T x : Ax \leq b,\ x \geq 0\}$
		be the LP relaxation of an IP, where $A$ is totally unimodular and $b\in\mathbb Z^m$. Suppose that the LP has an optimal solution. Then it also admits an integral optimal solution.
	\end{llemma}
	\begin{proof}
		Introduce slack variables $s\in \mathbb{R}^m$ and $s \geq 0$, so that $Ax+s=b.$
		Then the LP can be written in standard form as
		\[
		\max \left\{
		\begin{bmatrix}
			c \\
			0
		\end{bmatrix}^T
		\begin{bmatrix}
			x \\
			s
		\end{bmatrix}
		:
		\begin{bmatrix}
			A & I_m
		\end{bmatrix}
		\begin{bmatrix}
			x \\
			s
		\end{bmatrix}
		=b,\ x\geq 0,\ s\geq 0
		\right\}.
		\]
		
		Let
		\[
		M=\begin{bmatrix} A & I_m \end{bmatrix}.
		\]
		Since $A$ is totally unimodular, and $I_m$ is obtained by appending the unit vectors $e_1,\dots,e_m$, the previous result implies that $M=[A\ I_m]$ is also totally unimodular.
		
		By the fundamental theorem of linear programming, since the linear program has an optimal solution, it has an optimal basic feasible solution (we could get one using the simplex method). Let
		\[
		z^*=
		\begin{bmatrix}
			x^* \\
			s^*
		\end{bmatrix}
		\]
		be such an optimal basic feasible solution. Then there exists a basis matrix $M_B$, consisting of linearly independent columns of $M$, such that
		\[
		z_B^* = M_B^{-1}b,
		\]
		and all nonbasic variables are equal to $0$.
		
		Now $M_B$ is a nonsingular square submatrix of $M$. Since $M$ is totally unimodular,
		\[
		\det(M_B)\in \{-1,0,1\}.
		\]
		But \(M_B\) is nonsingular, so
		\[
		\det(M_B)=\pm 1.
		\]
		Therefore,
		\[
		M_B^{-1}=\frac{\operatorname{adj}(M_B)}{\det(M_B)}
		\]
		has integer entries, because \(M_B\) has integer entries and \(\det(M_B)=\pm 1\). Since \(b\in \mathbb{Z}^m\), it follows that
		\[
		z_B^*=M_B^{-1}b
		\]
		is integral. The nonbasic variables are zero, hence they are also integral. Therefore,
		\[
		z^*=
		\begin{bmatrix}
			x^* \\
			s^*
		\end{bmatrix}
		\in \mathbb{Z}^{n+m}.
		\]
		In particular,
		\[
		x^*\in \mathbb{Z}^n.
		\]
		Thus the original linear program has an integral optimal solution.
	\end{proof}
	
	Consequently, we can deduce the following corollary.
	
	\begin{ccor} \label{IntPolyTU}
		The feasible region of a linear program with totally unimodular constraint matrix and integral right-hand side forms an integral polyhedron.
	\end{ccor}
	
	To see why, suppose for contradiction, that $P$ has a non-integral vertex $v$. Since $v$ is a vertex, there exists a vector $c$ such that $v$ is the unique optimal solution of $\max\{c^Tx : x\in P\}$. Since the constraint matrix is totally unimodular and the right-hand side is integral, the above linear program admits an integral optimal solution $x^*$. However, the optimal solution is unique, and therefore $x^*=v$. This implies that $v$ is integral, which contradicts our assumption. Hence every vertex of $P$ is integral, and so $P$ is integral.
	

\section{The Bipartite Matching Polytope}

	We solved the maximum bipartite matching problem algorithmically  in \Cref{2.2}. In this section, we will solve the same problem in terms of linear programming. Let $G = (V_{1} \cup V_{2}, E)$ be a bipartite graph with $n$ vertices $v_{1}, \ldots, v_{n}$ and $m$ edges $e_{1}, \ldots, e_{m}$ and let $\delta(v)$ denote the set of edges incident to $v$. The IP describing the problem is the following:
	
	\begin{equation}
		\label{matching-ip}
		\begin{array}{r@{\quad}l}
			\max & \displaystyle\sum_{e\in E} x_e \\[2mm]
			\text{s.t.} &
			\begin{aligned}[t]
				\displaystyle\sum_{e\in \delta(v)} x_e &\leq 1,
				&& \forall v\in V(G),\\
				x_e &\geq 0,
				&& \forall e\in E,\\
				x_e &\in \mathbb{Z},
				&& \forall e\in E.
			\end{aligned}
		\end{array}
	\end{equation}
	
	or in compact form:
	
	\begin{equation}
		\label{mbm-compact}
		\begin{array}{r@{\quad}l}
			\max & \displaystyle\sum_{j=1}^{m} x_j \\[2mm]
			\text{s.t.} &
			\begin{aligned}[t]
				Ax &\leq \mathbf{1},\\
				x &\geq 0,\\
				x &\in \mathbb{Z}^{m}.
			\end{aligned}
		\end{array}
	\end{equation}	
	

	where $\mathbf{1}$ is a vector with $n$ components, each equal to $1$ and the matrix $A$ is defined as:
	
	\[
	A_{v,e} =
	\begin{cases}
		1, & \text{if  } v \text{ is incident to edge } e,\\
		0, & \text{otherwise.}
	\end{cases}
	\]
	
	In fact, $x$'s components can be $0$ or $1$ based on the constraint matrix, so we could simply write $x_{j} \in \{0, 1\}$. Consider now the LP relaxation of \eqref{mbm-compact}.
	
	\begin{equation} \label{mbm-compact-LP-Relaxation}
		\begin{array}{r@{\quad}l}
			\max & \displaystyle\sum_{j=1}^{m} x_j \\[2mm]
			\text{s.t.} &
			\begin{aligned}[t]
				Ax &\leq \mathbf{1},\\
				x &\geq 0.
			\end{aligned}
		\end{array}
	\end{equation}	
	
	Since the feasible region is non-empty and bounded, it is a polytope, guaranteeing that the LP relaxation has an optimal solution at a vertex. The polytope of \eqref{mbm-compact-LP-Relaxation} is integral. To prove it, it's sufficient (see \Cref{IntPolyTU}) to show that $A$ is totally unimodular, since the right-hand side vector $\mathbf{1}$ is integral.
	
	\begin{llemma}
		Let $G=(V_{1}\cup V_{2},E)$ be a bipartite graph, and let $A$ be its vertex-edge incidence matrix. Then $A$ is totally unimodular.
	\end{llemma}
	
	\begin{proof}
		We prove that every square submatrix of $A$ has determinant equal to $0$, $1$, or $-1$.
		
		Let $Q$ be an arbitrary square submatrix of $A$. We use induction on the size of $Q$. If $Q$ is a $1 \times 1$ matrix, then its determinant is either $0$ or $1$, since all entries of $A$ are $0$ or $1$.
		
		Now suppose that $Q$ has size $k \times k$, with $k \geq 2$, and assume that the claim holds for all smaller square submatrices of $A$.
		
		Since $A$ is the vertex-edge incidence matrix of $G$, every column of $A$ contains exactly two entries equal to $1$, one corresponding to each endpoint of the edge. Therefore, every column of $Q$ contains at most two entries equal to $1$.
		
		If some column of $Q$ contains no entry equal to $1$, then this column is zero, and hence
		\[
		\det(Q)=0.
		\]
		
		If some column of $Q$ contains exactly one entry equal to $1$, then we expand the determinant along this column. We get
		\[
		\det(Q)=\pm \det(Q'),
		\]
		where $Q'$ is a square submatrix of $A$ of size $(k-1)\times(k-1)$. By the induction hypothesis,
		\[
		\det(Q')\in\{-1,0,1\}.
		\]
		Therefore,
		\[
		\det(Q)\in\{-1,0,1\}.
		\]	
		
		It remains to consider the case where every column of $Q$ contains exactly two entries equal to $1$. Since $G$ is bipartite, every edge has one endpoint in $V_1$ and one endpoint in $V_2$. Hence, in every column of $Q$, one of the two $1$'s appears in a row corresponding to a vertex of $V_1$, and the other appears in a row corresponding to a vertex of $V_2$.
		
		Therefore, the sum of the rows of $Q$ corresponding to vertices in $V_1$ is equal to the sum of the rows of $Q$ corresponding to vertices in $V_2$. Hence, the rows of $Q$ are linearly dependent, and so
		\[
		\det(Q)=0.
		\]		
		
		In all cases, we have
		\[
		\det(Q)\in\{-1,0,1\}.
		\]
	\end{proof}
	
	Since the polytope of the LP relaxation contains all feasible solutions of the IP, the LP relaxation can only have an optimal value at least as large as that of the IP. However, the polytope of the LP relaxation is integral and since it has an optimal solution at a vertex, this optimal solution is also integral. This optimal solution is feasible for the original IP as well, since each component of the solution is either $0$ or $1$. Consequently, the LP relaxation and the IP have the same optimal value, so we can solve the LP instead of the IP to obtain a maximum matching.
	
	Another famous problem in graph theory, is the \emph{minimum vertex cover}. A \emph{vertex cover} of a graph $G$ is a set of nodes such that each edge of the graph has at least one endpoint in the set. The minimum vertex cover problem asks for a vertex cover of minimum cardinality. This problem is NP-hard in a general graph. However, if the graph is bipartite, we can solve it in polynomial time. In fact, the following theorem holds.
	
	\begin{ttheorem}[K\"onig's Theorem]
		Let $G=(V_1\cup V_2,E)$ be a bipartite graph. Then the maximum cardinality of a matching in $G$ is equal to the minimum cardinality of a vertex cover in $G$.
	\end{ttheorem}
	
	\begin{proof}
		(Based on \cite[Chapter 8, pp. 146-147]{matousek2007understanding}) Let $A$ be the vertex-edge incidence matrix of $G$. Consider the LP relaxation \eqref{mbm-compact-LP-Relaxation} of the maximum matching problem. We have shown that, since $A$ is totally unimodular and the right-hand side vector is integral, the optimal value of this relaxation is equal to the maximum cardinality of a matching in $G$.
		
		The dual of this LP relaxation is
		\[
		\begin{array}{r@{\quad}r@{\;}c@{\;}l}
			\min & \mathbf{1}^T y \\[2mm]
			\text{s.t.}
			& A^T y & \geq & \mathbf{1},\\
			& y & \geq & 0.
		\end{array}
		\]
		This is exactly the LP relaxation of the minimum vertex cover problem. Indeed, the IP for minimum vertex cover is
		\[
		\begin{array}{r@{\quad}r@{\;}c@{\;}l}
			\min & \mathbf{1}^T y \\[2mm]
			\text{s.t.}
			& A^T y & \geq & \mathbf{1},\\
			& y & \geq & 0,\\
			& y & \in & \mathbb{Z}^{n}.
		\end{array}
		\]
		Here $y_v=1$ means that the vertex $v$ is chosen in the vertex cover. The constraint $A^Ty\geq \mathbf{1}$ says that for every edge, at least one of its endpoints must be chosen.
		
		Since $A$ is totally unimodular, it is easy to see that $A^T$ is also totally unimodular. Therefore, again by the total unimodularity result, the LP relaxation of the minimum vertex cover problem has an integral optimal solution. Moreover, in an optimal integral solution we may assume that every component is either $0$ or $1$, since if $y_v>1$, replacing $y_v$ by $1$ keeps all constraints feasible and does not increase the objective value (in fact, it is impossible to happen, since this would strictly decreases the objective value, contradicting optimality). Hence, the optimal value of the vertex cover LP relaxation is equal to the minimum cardinality of a vertex cover in $G$.
		
		Finally, by strong duality, the optimal values of the two LP relaxations are equal. The first one is equal to the maximum cardinality of a matching in $G$, and the second one is equal to the minimum cardinality of a vertex cover in $G$. Therefore, these two quantities are equal.
	\end{proof}

\section{The Stable Matching Polytope} \label{sec:stable-matching-polytope}
	
	In Section 2.3, we studied the stable marriage problem from an algorithmic point of view. In particular, the Gale--Shapley algorithm computes a stable marriage in polynomial time \cite{Gale01011962}. In this section, we study the same problem from a polyhedral point of view.
	
	We keep the same assumptions as before. There are $n$ men and $n$ women, all preference lists are complete and strict, and every feasible solution is a marriage. Let
	\[
	U=\{m_1,m_2,\dots,m_n\}
	\]
	be the set of men and
	\[
	V=\{w_1,w_2,\dots,w_n\}
	\]
	be the set of women. For a man $m$, we write $w'\succ_m w$ if $m$ prefers woman $w'$ to woman $w$. Similarly, for a woman $w$, we write $m'\succ_w m$ if $w$ prefers man $m'$ to man $m$.
	
	For every pair $(m,w)\in U\times V$, define a variable
	\[
	x_{mw}=
	\begin{cases}
		1, & \text{if } m \text{ is matched with } w,\\
		0, & \text{otherwise}.
	\end{cases}
	\]
	
	Then the stable marriage problem can be written as the following IP:
	\begin{equation}
		\label{stable-marriage-ip}
		\begin{aligned}
			\sum_{w\in V} x_{mw} &= 1,
			&& \forall m\in U,\\
			\sum_{m\in U} x_{mw} &= 1,
			&& \forall w\in V,\\
			x_{mw}
			+
			\sum_{\substack{w'\in V\\ w'\succ_m w}} x_{mw'}
			+
			\sum_{\substack{m'\in U\\ m'\succ_w m}} x_{m'w}
			&\geq 1,
			&& \forall (m,w)\in U\times V,\\
			x_{mw} &\in \{0,1\},
			&& \forall (m,w)\in U\times V.
		\end{aligned}
	\end{equation}
	
	The first two families of constraints say that each man is matched with exactly one woman and each woman is matched with exactly one man. Hence, they describe a marriage.
	
	The third family of constraints expresses stability. Fix a pair $(m,w)$. The inequality says that at least one of the following must happen:
	\[
	m \text{ is matched with } w,
	\]
	or
	\[
	m \text{ is matched with a woman he prefers to } w,
	\]
	or
	\[
	w \text{ is matched with a man she prefers to } m.
	\]
	If none of these happens, then $m$ and $w$ prefer each other to their assigned partners. Therefore, $(m,w)$ is a blocking pair.
	
	\begin{llemma}
		The feasible integer points of \eqref{stable-marriage-ip} are exactly the incidence vectors of stable marriages.
	\end{llemma}
	
	\begin{proof}
		Let $x$ be a feasible integer point of \eqref{stable-marriage-ip}. Since $x_{mw}\in\{0,1\}$, the first two families of constraints define a marriage. Let $N$ be this marriage.
		
		We show that $N$ is stable. Suppose for the sake of contradiction that there exists a blocking pair $(m,w)$. Then $m$ is not matched with $w$, so
		\[
		x_{mw}=0.
		\]
		Also, since $m$ prefers $w$ to his assigned partner, $m$ is not matched with any woman $w'$ such that $w'\succ_m w$. Thus,
		\[
		\sum_{\substack{w'\in V\\ w'\succ_m w}} x_{mw'}=0.
		\]
		Similarly, since $w$ prefers $m$ to her assigned partner, $w$ is not matched with any man $m'$ such that $m'\succ_w m$. Hence,
		\[
		\sum_{\substack{m'\in U\\ m'\succ_w m}} x_{m'w}=0.
		\]
		Therefore, the stability constraint for the pair $(m,w)$ is violated. This is a contradiction. Hence, $N$ is stable.
		
		Conversely, let $N$ be a stable marriage and let $\chi^N$ be its incidence vector. The first two families of constraints are clearly satisfied. Now fix a pair $(m,w)$. If $m$ is matched with $w$, then the stability inequality is satisfied because $x_{mw}=1$. Otherwise, since $N$ is stable, the pair $(m,w)$ is not blocking. Therefore, either $m$ is matched with a woman he prefers to $w$, or $w$ is matched with a man she prefers to $m$. Hence, the stability inequality is again satisfied.
	\end{proof}
	
	
	We now define the polytope associated with stable marriages.
	
	\begin{ddef}
		The $\mathit{stable}$ $\mathit{matching}$ $\mathit{polytope}$, also called the $\mathit{stable}$ $\mathit{marriage}$ $\mathit{polytope}$ in this setting, is
		\[
		P_{SM}
		=
		\operatorname{conv}
		\left\{
		\chi^N\in \mathbb{R}^{U\times V}
		:
		N \text{ is a stable marriage}
		\right\}.
		\]
	\end{ddef}
	
	Thus, $P_{SM}$ is the convex hull of all incidence vectors of stable marriages. It contains all stable marriages as integral points, but it may also contain fractional points. For example, if $N_1$ and $N_2$ are two different stable marriages, then $\frac{1}{2}\chi^{N_1}+\frac{1}{2}\chi^{N_2}$
	is usually fractional and also belongs to $P_{SM}$.
	
	Let $Q_{SM}$ be the polyhedron obtained from \eqref{stable-marriage-ip} by replacing the constraints $x_{mw}\in\{0,1\}$
	with $x_{mw}\geq 0.$
	Since the first two families of constraints imply $x_{mw}\leq 1$, no separate upper bound is needed.
	
	The important question is whether this linear relaxation introduces fractional vertices. In fact, the relaxation is \emph{exact}.
	
	\begin{ttheorem}[Vande Vate \cite{VandeVate1989}; Rothblum \cite{Rothblum1992}]
		For every stable marriage instance with complete and strict preference lists,
		\[
		Q_{SM}=P_{SM}.
		\]
		Equivalently, every extreme point of $Q_{SM}$ is the incidence vector of a stable marriage.
	\end{ttheorem}
	
	The nontrivial part of the theorem is that the polyhedron $Q_{SM}$ has no fractional extreme points, so $Q_{SM}$ is \emph{integral}. Therefore, every fractional feasible point of $Q_{SM}$ can be written as a convex combination of incidence vectors of stable marriages, and is not a new vertex of the relaxation.
	
	This gives a complete linear description of the stable matching polytope:
	\[
	P_{SM}
	=
	\left\{
	x\in\mathbb{R}_{\geq 0}^{U\times V}
	:
	\begin{array}{ll}
		\sum_{w\in V}x_{mw}=1, & \forall m\in U,\\[2mm]
		\sum_{m\in U}x_{mw}=1, & \forall w\in V,\\[2mm]
		x_{mw}
		+
		\sum_{\substack{w'\in V\\ w'\succ_m w}}x_{mw'}
		+
		\sum_{\substack{m'\in U\\ m'\succ_w m}}x_{m'w}
		\geq 1,
		& \forall (m,w)\in U\times V.
	\end{array}
	\right\}.
	\]
	
	The formulation has $n^2$ variables, $2n$ assignment constraints, and $n^2$ stability constraints, apart from non-negativity. Hence, it is a compact linear formulation.
	
	\paragraph{Consequences.}
	The Gale--Shapley algorithm is enough if we only want to find one stable marriage. The polyhedral formulation is useful when we want to optimize a linear objective over all stable marriages. For example, if each pair $(m,w)$ has weight $c_{mw}$, we may solve

	\begin{equation} \label{optimal-stable-marriage-lp}
		\begin{aligned}
			\max \quad & \sum_{m\in U}\sum_{w\in V} c_{mw}x_{mw} \\
			\text{s.t.} \quad & x\in Q_{SM}.
		\end{aligned}
	\end{equation}

	Because every extreme point of $Q_{SM}$ is integral, there exists an optimal extreme point of \eqref{optimal-stable-marriage-lp} that is the incidence vector of a stable marriage. Therefore, the optimal stable marriage problem with a linear objective can be solved as an LP.
	
	This section gives only a brief polyhedral view of the stable marriage problem. We introduced the natural integer formulation, defined the stable matching polytope, and stated the main result that its linear relaxation is integral. Together with the maximum bipartite matching formulation studied in the previous section, this gives another example where the natural linear relaxation is integral. However, this is not the case for many other matching problems. In the next chapter, we will study one such case.


\chapter{Pareto Matchings in one-to-one Models} 

\section{Model and Definitions} \label{def-pareto}

	In Sections $2.3$ and $3.3$, we studied the stable marriage problem, where there are $n$ men and $n$ women, and each participant has a preference list containing all members of the opposite side. Therefore, every stable matching matches all participants.
	
	In this chapter, we study a different setting, where the two sides need not have the same size, and only one side has preferences over the other side. For these reasons, it is natural to formulate this matching problem in the setting of a housing market.
	
	The \emph{house allocation problem} has been studied from an algorithmic point of view in \cite{abraham2004pareto}. An integer programming formulation for the same setting was later proposed by Eirinakis, Magos, and Mourtos \cite{eirinakis2015model}. In this chapter, we follow the notation and the basic definitions used in these works.
	
	House allocation is a one-sided matching problem. We are given a finite set
	\[
	A=\{a_1,\ldots,a_r\}
	\]
	of applicants and a finite set
	\[
	H=\{h_1,\ldots,h_s\}
	\]
	of houses. The houses are indivisible objects, and no monetary transfers are allowed. 
	In contrast with two-sided matching models, only the applicants have preferences.
	
	Each applicant $a\in A$ finds acceptable only some houses in $H$. We denote by
	$P(a)$ the preference list of applicant $a$. The list $P(a)$ is strict, so no ties are
	allowed. If $h,h'\in P(a)$, then
	\[
	h \succ_{a} h'
	\]
	means that applicant $a$ prefers house $h$ to house $h'$.
	
	The acceptable pairs define a bipartite graph
	\[
	G=(A,H,E),
	\]
	where
	\[
	E=\{(a,h)\in A\times H: h\in P(a)\}.
	\]
	Thus, an edge $(a,h)$ means that house $h$ is acceptable to applicant $a$.
	
	For each house \(h\in H\), let
	\[
	Q(h)=\{a\in A: h\in P(a)\}.
	\]
	Therefore, $Q(h)$ is the set of applicants whose preference list contains house $h$.
	
	A matching is a set $M\subseteq E$ such that each applicant is assigned to at most
	one house and each house is assigned to at most one applicant. If $(a,h)\in M$,
	then we write
	\[
	M(a)=h
	\quad\text{and}\quad
	M(h)=a.
	\]
	If an applicant or a house is not assigned in $M$, then we write
	\[
	M(z)=\emptyset,
	\quad z\in A\cup H.
	\]
	Thus, in this model, every feasible allocation is \emph{one-to-one}: no applicant receives
	more than one house and no house is given to more than one applicant.
	
	A matching $M'$ is a \emph{Pareto improvement} over a matching $M$ if every applicant
	is at least as well off in $M'$ as in $M$, and at least one applicant is strictly better
	off. Here, being unmatched is considered worse than being assigned any acceptable
	house. A matching $M$ is Pareto optimal if no Pareto improvement over $M$
	exists.
	
	We next recall three properties of matchings that will be useful for describing
	Pareto optimality.
	
	A matching $M$ is \emph{maximal} if there is no acceptable pair $(a,h)\in E$ such
	that
	\[
	M(a)=M(h)=\emptyset.
	\]
	In other words, no additional acceptable pair can be added to \(M\) without
	violating the matching constraints.
	
	A matching $M$ is \emph{trade-in free} if there is no applicant $a\in A$ and no house
	$h\in P(a)$ such that
	\[
	M(a)\neq \emptyset,\qquad M(h)=\emptyset,
	\qquad\text{and}\qquad h \succ_{a} M(a).
	\]
	Thus, no matched applicant can improve the current assignment by replacing the
	assigned house with an unmatched house.
	
	A matching $M$ is \emph{coalition free} if it does not admit a coalition. A coalition is
	a sequence of matched applicants
	\[
	C=\langle a_{i_0},a_{i_1},\ldots,a_{i_{k-1}}\rangle,
	\quad k\geq 2,
	\]
	such that
	\[
	M(a_{i_{c+1}}) \succ_{a_{i_c}} M(a_{i_c}),
	\quad c=0,\ldots,k-1,
	\]
	where the indices are taken modulo $k$. If such a sequence exists, then the
	applicants in $C$ can cyclically exchange their assigned houses, and every applicant in
	the sequence becomes strictly better off.
	
	The following characterization connects these three properties with Pareto
	optimality.
	
	\begin{pprop}[{\cite[Chapter 2, p. 6]{abraham2004pareto}}]
		A matching $M$ is Pareto optimal if and only if $M$ is maximal, trade-in free,
		and coalition free.
	\end{pprop}
	
	This characterization is the basis of the integer programming formulation that
	will be presented in the next section.
	
	For this formulation, it is useful to define coalitions independently of a specific
	matching. A plausible coalition is a set of applicant-house pairs
	\[
	C=\{(a_{i_c},h_{i_c}): c=0,\ldots,k-1\},
	\quad k\geq 2,
	\]
	such that, for every \(c=0,\ldots,k-1\),
	\[
	h_{i_{c+1}} \succ_{a_{i_c}} h_{i_c},
	\qquad
	\{h_{i_c},h_{i_{c+1}}\}\subseteq P(a_{i_c}),
	\]
	where again the indices are taken modulo $k$. If all pairs of such a set appear
	simultaneously in a matching, then the corresponding applicants form a coalition.
	We denote by $\mathcal C$ the family of all plausible coalitions.
	
	Finally, for every acceptable pair $(a,h)\in E$, we define a binary variable
	$x_{ah}$. For a matching $M$, its \emph{incidence vector} is the vector $x^M\in
	\{0,1\}^{E}$,  given by
	\[
	x^M_{ah}=
	\begin{cases}
		1, & \text{if } (a,h)\in M,\\
		0, & \text{otherwise.}
	\end{cases}
	\]
	These incidence vectors will later be used to define the Pareto matching
	polytope.


\section{An Integer Programming Formulation}
	
	We now present an integer programming formulation for Pareto optimal matchings,
	following Eirinakis, Magos, and Mourtos \cite{eirinakis2015model}. The formulation uses the
	characterization stated in the previous section: a matching is Pareto optimal if
	and only if it is maximal, trade-in free, and coalition free.
	
	For every acceptable pair $(a,h)$, where $a\in A$ and $h\in P(a)$, we define a
	binary variable $x_{ah}$. The meaning of this variable is
	\[
	x_{ah}=
	\begin{cases}
		1, & \text{if applicant } a \text{ is assigned to house } h,\\
		0, & \text{otherwise.}
	\end{cases}
	\]
	Thus, a vector $x$ represents a set of applicant-house pairs, and the constraints below
	force this set to be a Pareto optimal matching.
	
	First, we need the usual matching constraints. Each applicant can be assigned to at
	most one house, and each house can be assigned to at most one applicant. Hence, we
	require
	\[
	\sum_{h\in P(a)} x_{ah} \leq 1,
	\qquad \forall a\in A,
	\]
	and
	\[
	\sum_{a\in Q(h)} x_{ah} \leq 1,
	\qquad \forall h\in H.
	\]
	The first family of constraints controls the applicants, while the second family
	controls the houses.
	
	Next, we impose maximality. Fix an acceptable pair $(a,h)$. If applicant $a$ is
	unmatched and house $h$ is also unmatched, then the pair $(a,h)$ could be added
	to the matching. This is exactly what maximality forbids. Therefore, for every
	$a\in A$ and every $h\in P(a)$, we require
	\[
	\sum_{h'\in P(a)} x_{ah'}
	+
	\sum_{a'\in Q(h)\setminus\{a\}} x_{a'h}
	\geq 1.
	\]
	The first sum says whether applicant $a$ is matched to some house. The second sum
	says whether house $h$ is matched to some applicant different from $a$. Hence, the
	constraint prevents the case in which $a$ and $h$ are both unmatched.
	
	We also need to exclude trade-ins. Fix an applicant $a$ and a house $h\in P(a)$.
	If house $h$ is unmatched, then applicant $a$ must not be assigned to a house that
	is less preferred than $h$. Otherwise, applicant $a$ could drop the current assignment and move to the free house $h$. This is expressed by
	\[
	\sum_{a'\in Q(h)} x_{a'h}
	-
	\sum_{\substack{h'\in P(a)\\ h \succ_{a} h'}} x_{ah'}
	\geq 0,
	\qquad \forall a\in A,\ \forall h\in P(a).
	\]
	Indeed, if house $h$ is unmatched, then the first sum is equal to $0$. The
	constraint then forces all variables $x_{ah'}$ with $h \succ_{a} h'$ to be equal to $0$.
	Thus, applicant $a$ cannot be assigned to a worse house while $h$ is free.
	
	Finally, we need to exclude coalitions. Let $C\in\mathcal C$ be a plausible
	coalition. If all pairs in $C$ appeared simultaneously in a matching, then the
	corresponding applicants would be able to cyclically exchange houses and all become
	strictly better off. Therefore, at least one pair of every plausible coalition must be
	absent from the matching. This gives the constraints
	\[
	\sum_{(a,h)\in C} x_{ah} \leq |C|-1,
	\qquad \forall C\in\mathcal C.
	\]
	
	Putting all constraints together, we obtain the following integer programming
	formulation:
	\begin{equation}
		\label{pareto-matching-ip}
		\begin{aligned}
			\sum_{h\in P(a)} x_{ah} &\leq 1,
			&& \forall a\in A,\\
			\sum_{a\in Q(h)} x_{ah} &\leq 1,
			&& \forall h\in H,\\
			\sum_{h'\in P(a)} x_{ah'}
			+
			\sum_{a'\in Q(h)\setminus\{a\}} x_{a'h}
			&\geq 1,
			&& \forall a\in A,\ \forall h\in P(a),\\
			\sum_{a'\in Q(h)} x_{a'h}
			-
			\sum_{\substack{h'\in P(a)\\ h \succ_{a} h'}} x_{ah'}
			&\geq 0,
			&& \forall a\in A,\ \forall h\in P(a),\\
			\sum_{(a,h)\in C} x_{ah} &\leq |C|-1,
			&& \forall C\in\mathcal C,\\
			x_{ah} &\in \{0,1\},
			&& \forall a\in A,\ \forall h\in P(a).
		\end{aligned}
	\end{equation}
	
	The first two families of constraints ensure that the selected pairs form a
	matching. The third family enforces maximality, the fourth family enforces the
	trade-in free property, and the fifth family excludes coalitions. Therefore, by the
	characterization of Pareto optimal matchings, the feasible integer points of
	\eqref{pareto-matching-ip} are exactly the incidence vectors of Pareto optimal
	matchings. We refer to these as POM vectors.
	
	The formulation is written as a feasibility problem, since our goal is to describe
	the set of Pareto optimal matchings rather than optimize a particular objective
	function. 


\section{Linear Relaxation and the Separation Problem} \label{linear-relaxation}

	The next step is to study the LP relaxation of \eqref{pareto-matching-ip} as we similarly did for other known problems in chapter $3$. We saw that those problems had an integral feasible region, which means we could obtain an optimal value by solving their LP relaxation, and, for this reason, get our answer in polynomial time. Unfortunately, this is not the case for the house allocation problem. 
	
	Consider the LP relaxation of \eqref{pareto-matching-ip} by removing the constraints $x_{ah} \in \{0,1\}, \forall a\in A,\ \forall h\in P(a)$ and adding $x_{ah} \geq 0, \forall a\in A,\ \forall h\in P(a)$. Because of the matching constraints, the feasible region is bounded. To prove that the polytope is not integral, it's sufficient to find a fractional vertex. To do this, we will actually do a brute force using the \Cref{hyperplane-th}. More specifically, we will generate random coefficients to construct an objective function and then solving the resulting LP using the simplex method (which \emph{guarantees} that we will get a vertex). We will repeat these steps until we find a fractional vertex.

	\paragraph{Separation.} Notice that the family of coalition constraints may be large. In fact, the size of $\mathcal C$ can be factorial (or even larger). 
	Consider an instance with five applicants and twenty-five houses. Let the houses be divided into five blocks
	\[
	H_1=\{1,2,3,4,5\},\quad
	H_2=\{6,7,8,9,10\},\quad
	H_3=\{11,12,13,14,15\},
	\]
	\[
	H_4=\{16,17,18,19,20\},\quad
	H_5=\{21,22,23,24,25\}.
	\]
	Denote the $j$-th house of block $H_i$ by $h_{i,j}$. Assume that applicant $a_i$ ranks all houses of $H_{i+1}$ above all houses of $H_i$, where the index is taken cyclically ($H_6=H_1$). Then, for every permutation $\pi$ of the set $\{1,2,3,4,5\}$, the set
	\[
	C_\pi=
	\{(a_1,h_{1,\pi(1)}),(a_2,h_{2,\pi(2)}),(a_3,h_{3,\pi(3)}),
	(a_4,h_{4,\pi(4)}),(a_5,h_{5,\pi(5)})\}
	\]
	forms a plausible coalition. Indeed, applicant $a_1$ prefers $h_{2,\pi(2)}$ to $h_{1,\pi(1)}$, applicant $a_2$ prefers $h_{3,\pi(3)}$ to $h_{2,\pi(2)}$, and so on, while applicant $a_5$ prefers $h_{1,\pi(1)}$ to $h_{5,\pi(5)}$. Therefore, each such permutation defines a distinct plausible coalition. Since there are $5!$ permutations of \(\{1,2,3,4,5\}\), this construction gives at least
	$5! = 120$ distinct plausible coalitions. More generally, the same construction with $n$ applicants and $n$ houses in each block gives at least $n!$ plausible coalitions. This shows why generating all these constraints upfront is impractical, making a separation procedure essential. 
	
	The envy graph used in {\cite[Chapter 2, p. 6]{abraham2004pareto}} is defined with respect to a fixed matching $M$. In that graph, the vertices are the applicants, and an edge from $a_i$ to $a_j$ means that $a_i$ would prefer the house assigned to $a_j$ in $M$. Thus, for a matching $M$, coalitions can be detected by looking for directed cycles in this graph.
	
	In our separation procedure, we use a slightly different \emph{auxiliary graph}, since the current solution of the LP relaxation need not correspond to a matching. The vertices of this graph are the assignment pairs
	\[
	V=\{(a,h): h\in P(a)\}.
	\]
	For two vertices $(a,h)$ and $(a^{'},h^{'})$, with $a\neq a'$, we add a directed edge
	\[
	(a,h)\longrightarrow (a',h')
	\]
	whenever applicant $a$ strictly prefers $h'$ to $h$. 
	
	A plausible coalition corresponds to a directed cycle in the auxiliary graph. Let $x^*$ be the current solution of the LP relaxation. To separate the coalition-free constraints, we assign to each vertex $(a,h)$ the weight
	\[
	w(a,h)=1-x^*_{ah}.
	\]
	For a plausible coalition $C$, the corresponding coalition inequality is
	\[
	\sum_{(a,h)\in C} x_{ah}\leq |C|-1.
	\]
	At the point $x^*$, this inequality is violated if and only if
	\[
	\sum_{(a,h)\in C} x^*_{ah}>|C|-1,
	\]
	or equivalently,
	\begin{equation}\label{cycle-condition}
		\sum_{(a,h)\in C} (1-x^*_{ah})<1.
	\end{equation}
	Hence, the separation problem reduces to finding a minimum-weight directed cycle in the auxiliary graph. If the weight of such a cycle is less than $1$, then the corresponding coalition constraint is violated and is added to the relaxation. Otherwise, no coalition-free constraint is violated by the current LP solution.
	
	The separation procedure is implemented as a cutting-plane procedure. We first solve the LP relaxation without adding any coalition-free constraints. Using $x^*$, we then construct the auxiliary directed graph described above. The unweighted structure of this graph depends only on the preference lists. However, in each iteration, the vertex weights depend on the current LP solution.
	
	Since we will use the Floyd--Warshall algorithm \cite{floyd1962algorithm} and this algorithm applies only to edge-weighted graphs, we convert these vertex weights into edge weights. Assume a directed edge $((a, h), (a^{'},h^{'}))$ and let $u = (a, h)$ and $v = (a^{'},h^{'})$.
	We then set the edge weight ($w^{*}$) equal to the weight of the head vertex:
	\[
	w^{*}(u, v) = w(v).
	\]
	With this convention, the weight of a directed cycle is exactly the sum of the weights of its vertices.
	
	A small example of a coalition is illustrated in the following figure.
	
	\begin{figure}[H]
		\centering
		\begin{tikzpicture}[
			cnode/.style={circle, draw=black, thin, minimum size=1.6cm, font=\normalsize},
			edge/.style={->, >=Stealth, thick}
			]
			
			% Nodes
			\node[cnode] (n1) at (0, 0) {$(a_{1}, h_{1})$};
			\node[cnode] (n2) at (3.8, 0) {$(a_{2}, h_{2})$};
			\node[cnode] (n3) at (7.6, 0) {$(a_{3}, h_{3})$};
			\node[cnode] (n4) at (11.4, 0) {$(a_{4}, h_{4})$};
			
			% Forward Edges
			\draw[edge] (n1) -- (n2) node[midway, above, font=\small] {$1 - x^{*}_{a_{2}h_{2}}$};
			\draw[edge] (n2) -- (n3) node[midway, above, font=\small] {$1 - x^{*}_{a_{3}h_{3}}$};
			\draw[edge] (n3) -- (n4) node[midway, above, font=\small] {$1 - x^{*}_{a_{4}h_{4}}$};
			
			% Return Edge (curved below)
			\draw[edge] (n4) to[bend left=35] node[midway, below=0.15cm, font=\small] {$1 - x^{*}_{a_{1}h_{1}}$} (n1);
		\end{tikzpicture}
		\caption{A directed cycle in the auxiliary graph used for separation. Each vertex is an assignment pair $(a_i,h_i)$. The edge from $(a_i,h_i)$ to $(a_j,h_j)$ has weight $1-x^*_{a_jh_j}$.}
		\label{fig:directed-cycle}
	\end{figure}
	
	\noindent The directed cycle in the figure corresponds to the preference relations
	\[
	h_2 \succ_{a_1} h_1,\qquad
	h_3 \succ_{a_2} h_2,\qquad
	h_4 \succ_{a_3} h_3,\qquad
	h_1 \succ_{a_4} h_4.
	\]
	
	We then run the Floyd--Warshall algorithm on this weighted directed graph and obtain the all-pairs shortest-path distance matrix $D$. We do not inspect the diagonal entries $D_{u,u}$, since they correspond to the empty path and are equal to zero. Instead, for every directed edge $(u,v)$, we check whether there is a path from $v$ back to $u$. If such a path exists, then the edge $(u,v)$ together with a shortest path from $v$ to $u$ forms a directed cycle. Its weight is
	\[
	w^{*}(u,v)+D_{v,u}.
	\]
	Therefore, by checking the quantity $w^{*}(u,v)+D_{v,u}$ over all directed edges $(u,v)$, we find a minimum-weight directed cycle in the auxiliary graph.
	
	If the minimum cycle $C$ has weight strictly less than $1$, then the coalition-free constraint
	\[
	\sum_{(a,h)\in C}x_{ah}\leq |C|-1
	\]
	is violated by the current solution $x^*$. We add this inequality to the LP relaxation and solve the relaxation again.
	
	The process is repeated until the separation step finds no additional violated coalition-free constraint. At that point, the current LP solution satisfies both the coalition constraints that have already been added explicitly and all remaining coalition constraints that have not been generated. Hence, instead of generating all constraints of $\mathcal C$ in advance, we add only those that are actually violated during the solution process.

	\begin{llemma}
		The separation problem for the coalition-free constraints can be solved in polynomial time. More precisely, let $n=|A|$ be the number of applicants and let
		\[
		L=\max_{a\in A}|P(a)|
		\]
		be the maximum length of a preference list. Then one separation call can be performed in $O(n^3L^3)$ time.
	\end{llemma}
	
	\begin{proof}
		For each applicant $a\in A$, let $\ell_a=|P(a)|$ be the length of the preference list of $a$.
		Then
		\[
		r=\sum_{a\in A}\ell_a
		\]
		is the number of acceptable pairs, and therefore also the number of variables $x_{ah}$.
		
		The auxiliary graph has one vertex for each acceptable pair $(a,h)$. Hence,
		\[
		|V_G|=r\leq nL.
		\]
		
		We now estimate the number of edges. Fix a vertex $(a,h)$, and suppose that
		$h$ appears in position $t$ of the preference list $P(a)$. Then applicant $a$
		prefers exactly $t-1$ houses to $h$. For each such house $h'$, there can be
		edges to vertices of the form $(a',h')$, with $a'\neq a$. In the worst case,
		there are at most $n-1$ such vertices. Therefore, the outdegree of $(a,h)$ is
		at most
		\[
		(t-1)(n-1).
		\]
		Summing over all vertices, we obtain
		\[
		|E_G|
		\leq
		(n-1)\sum_{a\in A}\sum_{t=1}^{\ell_a}(t-1).
		\]
		Since
		\[
		\sum_{t=1}^{\ell_a}(t-1)
		=
		\frac{\ell_a(\ell_a-1)}{2},
		\]
		we get
		\[
		|E_G|
		\leq
		(n-1)\sum_{a\in A}\frac{\ell_a(\ell_a-1)}{2}.
		\]
		In particular, since $\ell_a\leq L$ for every applicant $a$, we have
		\[
		|E_G|
		\leq
		(n-1)n\frac{L(L-1)}{2}
		=
		O(n^2L^2).
		\]
		After the graph has been constructed, one separation call consists of the
		following steps. First, we assign weights to the vertices, which takes $O(r)$
		time. Then we convert these vertex weights into edge weights, which takes $O(n^2L^2)$. We then run the Floyd--Warshall algorithm on a graph with
		$r$ vertices, which takes
		\[
		O(r^3)
		\]
		time. Finally, we inspect all directed edges $(u,v)$ and check the value
		\[
		w^*(u,v)+D_{v,u}.
		\]
		This takes $O(n^2L^2)$ time.
		
		Hence, the total running time of one separation call is
		\[
		O(r^3+n^2L^2).
		\]
		Since $r\leq nL$, this is also
		\[
		O((nL)^3)=O(n^3L^3).
		\]
		In the case of complete preference lists with $n$ houses, we have $L=n$. In that case, the worst-case running time becomes
		\[
		O(n^6).
		\]
	\end{proof}
	
	\paragraph{Directed cycles that do not correspond to plausible coalitions.} The auxiliary graph may also contain directed cycles that do not correspond to plausible coalitions, because an applicant or a house may appear more than once. However, such cycles cannot lead to violated inequalities for any point satisfying the matching constraints. Indeed, if a directed cycle $C$ contains two vertices with the same applicant, then the applicant matching constraint implies that the sum of the corresponding variables is at most $1$, while all remaining variables in the cycle have value at most $1$. Hence, $\sum_{(a,h)\in C} x^*_{ah}\leq |C|-1$ holds.
	The same argument applies if a house appears more than once, using the house matching constraint. Therefore, every directed cycle with weight less than $1$ corresponds to a valid plausible coalition constraint that is violated by $x^*$.


\section{The Pareto Matching Polytope}

	In this section, we study the polytope obtained from the POM vectors. The goal is not to give a general closed-form description of this polytope (which we think it's a hard task), but rather to examine it computationally for small instances. This allows us to compare the true convex hull of Pareto optimal matchings with the linear relaxation studied in the previous section.
	
	We start from a fixed house allocation instance with applicant set $A$, house set $H$, and preference lists $P(a)$ for every applicant $a\in A$. For this instance, we first generate Pareto optimal matchings using the Serial Dictatorship algorithm (code: \eqref{sd-algorithm-code}). More precisely, we consider all possible permutations of the applicants. For each permutation, the applicants are processed one by one according to this order, and each applicant receives the most preferred house that is still available, if such a house exists.
	
	By the characterization theorem {\cite[Chapter 6, pp. 13-14]{abraham2004pareto}} for Pareto optimal matchings in house allocation, every outcome of Serial Dictatorship is Pareto optimal, and every Pareto optimal matching can be obtained from Serial Dictatorship for some ordering of the applicants. Therefore, by running Serial Dictatorship over all permutations of $A$ and removing duplicate outcomes, we get the set of Pareto optimal matchings of the instance.
	
	Each Pareto optimal matching $M$ is represented by its incidence vector $x^M$ as defined in \Cref{def-pareto}.
	
	After generating all Pareto optimal matchings, we obtain a finite set of binary vectors. The Pareto matching polytope of the instance is then defined as
	\[
	P_{\mathrm{POM}}=\operatorname{conv}\{x^M : M \text{ is a Pareto optimal matching}\}.
	\]
	This is the exact convex hull of all Pareto optimal matchings for the given instance.
	
	For small instances, we can compute this convex hull explicitly. Starting from the vertex description, given by the POM vectors, we use SageMath to compute the $H$-description of $P_{\mathrm{POM}}$. In other words, we obtain a description of the form
	\[
	P_{\mathrm{POM}}=\{x : Bx\leq d,\ Ex=f\},
	\]
	where the inequalities describe the facets of the polytope and the equations describe its affine hull.
	
	For each instance, we record basic statistics of the resulting polytope. These include the number of variables, the number of distinct Pareto optimal matchings, the dimension of the polytope, the number of equations in the affine hull, and the number of inequalities in the $H$-description. These statistics give a first indication of the structure of the Pareto matching polytope for the instance under consideration.
	
	The $H$-description also allows us to test whether a given point belongs to the true convex hull. In particular, if $x^*$ is a feasible solution of the LP relaxation, we can evaluate all equations and inequalities of the $H$-description at $x^*$. If one of them is violated, then $x^*$ does not belong to $P_{\mathrm{POM}}$. This gives a direct way to compare the LP relaxation with the actual Pareto matching polytope. This part of the project's source code can be found in \eqref{convex-hull-pareto-code}. 
	
	The purpose of this computational study is to understand the structure of $P_{\mathrm{POM}}$ on small instances. In the final chapter, we use these computations on concrete examples and analyze which inequalities of the true convex hull are violated by fractional solutions of the relaxation. 
	
	All the above computations can be found in \eqref{convex-hull-pareto-code}.

\section{Candidate Cutting Inequalities}

	After relaxing the binary restrictions to $0\le x_{ah}\le 1, a\in A,\ h\in P(a),$ some of the implications that are enforced by integrality are lost. As a result, the linear relaxation may contain fractional points which do not belong to the convex hull of POM vectors.
	
	In this section we introduce two families of valid inequalities that strengthen the linear relaxation. These inequalities are not claimed to give a complete description of the Pareto optimal matching polytope. Instead, they are candidate cutting inequalities motivated by the structure of Pareto optimality and by the fractional solutions that appear in the relaxation.
	
	We define
	\[
	y_h=\sum_{a\in Q(h)}x_{ah}.
	\]
	Thus $y_{h}$ represents whether the house $h$ is assigned. Also, for $a\in A$ and $h\in P(a)$, we define
	\[
	B_a(h)=\{g\in P(a):g\succ_{a} h\},
	\]
	that is, the set of houses that agent $a$ prefers to $h$. Similarly, we define
	\[
	W_a(h)=\{r\in P(a):h\succ_{a} r\},
	\]
	the set of houses that are worse than $h$ according to the preferences of $a$.
	
	\subsection{First-choice and prefix-cover inequalities}
	
	\paragraph{First-choice inequalities.} We first consider a simple but important implication of Pareto optimality. Suppose that a house $h$ is the first choice of some applicant $a$. Then, in every Pareto optimal matching (i.e. in every POM vector), the house $h$ must be assigned. Indeed, if $h$ were unmatched, then either $a$ would be unmatched, contradicting maximality, or $a$ would be matched to a worse house, contradicting trade-in freeness.
	
	Therefore, for every house $h$ that appears as the first choice of at least one applicant, the following inequality is valid for the Pareto optimal matching polytope:
	\[
	\sum_{b\in Q(h)}x_{bh}\ge 1.
	\]
	Together with the matching constraint
	\[
	\sum_{b\in Q(h)}x_{bh}\le 1,
	\]
	this implies
	\[
	\sum_{b\in Q(h)}x_{bh}=1.
	\]
	
	The reason why this inequality is useful is that the original relaxation does not necessarily enforce it. To see this, fix an applicant $a$ whose first choice is $h$. Since $h$ is the first choice of $a$, we have $B_a(h)=\varnothing$. The maximality constraint for the pair $(a,h)$ can be written as
	\[
	y_h+\sum_{r\in W_a(h)}x_{ar}\ge 1.
	\]
	The trade-in free constraint for the same pair is
	\[
	y_h-\sum_{r\in W_a(h)}x_{ar}\ge 0.
	\]
	If we write
	\[
	z_a=\sum_{r\in W_a(h)}x_{ar},
	\]
	then these two constraints become
	\[
	y_h+z_a\ge 1,
	\]
	and
	\[
	y_h\ge z_a.
	\]
	In the integer formulation, $y_h\in\{0,1\}$. Hence these two inequalities force $y_h=1$. In the linear relaxation, however, $y_h$ may be fractional. For example, the values
	\[
	y_h=\frac{1}{2},
	\qquad
	z_a=\frac{1}{2}
	\]
	satisfy both inequalities. Thus the relaxation may allow a first-choice house to be only partially assigned.
	
	The following small instance illustrates this phenomenon. Let
	\[
	A=\{a_1,a_2\},
	\qquad
	H=\{h_1,h_2\},
	\]
	with preference lists
	\[
	P(a_1)=\langle h_1,h_2\rangle,
	\qquad
	P(a_2)=\langle h_2\rangle.
	\]
	The unique Pareto optimal matching is
	\[
	M=\{(a_1,h_1),(a_2,h_2)\}.
	\]
	Indeed, the house $h_1$ is the first choice of $a_1$, so it must be assigned to $a_1$, and then maximality forces $a_2$ to be assigned to $h_2$.
	
	However, the linear relaxation admits the fractional point
	\[
	x_{11}=\frac{1}{2},
	\qquad
	x_{12}=\frac{1}{2},
	\qquad
	x_{22}=\frac{1}{2},
	\]
	with all other variables equal to zero. The matching constraints are satisfied, since
	\[
	x_{11}+x_{12}=1,
	\]
	\[
	x_{22}=\frac{1}{2}\le 1,
	\]
	and
	\[
	x_{12}+x_{22}=1.
	\]
	The maximality constraints are also satisfied. For example, for the pair $(a_1,h_1)$, the left-hand side is
	\[
	x_{11}+x_{12}=1,
	\]
	and for the pair $(a_2,h_2)$, the left-hand side is
	\[
	x_{22}+x_{12}=1.
	\]
	The trade-in constraint for $(a_1,h_1)$ is
	\[
	x_{11}-x_{12}\ge 0,
	\]
	which is satisfied with equality. There is no nontrivial coalition cycle in this instance. Hence this point is feasible for the original relaxation.
	
	Nevertheless, it is not contained in the convex hull of POM vectors, because in every POM vector the house $h_1$ is fully assigned to $a_1$. The first-choice inequality
	\[
	x_{11}\ge 1
	\]
	cuts off this fractional solution.

	\paragraph{Dimension.}
	This observation implies an important result concerning the dimension of the polytope. Let $F$ be the set of houses
	that appear as the first choice of at least one applicant. As shown above, every house $h\in F$ must be assigned in every Pareto optimal matching. Therefore,
	\[
	\sum_{a\in Q(h)}x_{ah}=1,\qquad h\in F,
	\]
	is an affine equality for $P_{\mathrm{POM}}$. Each equality contains only variables corresponding to one house, and therefore all these equalities are linearly independent.
	
	\begin{ccor}
		Let $F$ be the set of houses that appear as the first choice of at least one
		applicant. Then
		\[
		\dim(P_{\mathrm{POM}})\le |E|-|F|.
		\]
	\end{ccor}
	
	\paragraph{Prefix-cover inequalities.} The previous observation can be generalized. The first-choice inequality is only the special case of a broader family.
	\begin{pprop}
		For every applicant $a\in A$ and every house $h\in P(a)$, the inequality
		\[
		\sum_{b\in Q(h)}x_{bh}
		+
		\sum_{g\in B_a(h)}x_{ag}
		\ge 1
		\]
		is valid for the Pareto optimal matching polytope.
	\end{pprop}
	
	\begin{proof}
		Let $M$ be a Pareto optimal matching, and let $x$ be its incidence vector. We prove that
		\[
		\sum_{b\in Q(h)}x_{bh}
		+
		\sum_{g\in B_a(h)}x_{ag}
		\ge 1
		\]
		holds for $x$.
		
		There are two cases.
		
		First, suppose that the house $h$ is assigned in $M$. Then
		\[
		\sum_{b\in Q(h)}x_{bh}=1,
		\]
		and the inequality follows immediately.
		
		Second, suppose that the house $h$ is not assigned in $M$. Then
		\[
		\sum_{b\in Q(h)}x_{bh}=0.
		\]
		Since $h\in P(a)$, if applicant $a$ were unmatched, then the pair $(a,h)$ could be added to the matching, contradicting maximality. Therefore, $a$ must be matched to some house in $P(a)$.
		
		Moreover, $a$ cannot be matched to a house worse than $h$. If $a$ were matched to some $r\in W_a(h)$, then $h$ would be an unmatched house preferred by $a$ to the current assignment. This would contradict trade-in freeness.
		
		Thus, when $h$ is unmatched, applicant $a$ must be matched to a house $g\in B_a(h)$. Hence
		\[
		\sum_{g\in B_a(h)}x_{ag}=1.
		\]
		Therefore,
		\[
		\sum_{b\in Q(h)}x_{bh}
		+
		\sum_{g\in B_a(h)}x_{ag}
		=
		0+1
		=
		1.
		\]
		The inequality holds in both cases. Since it holds for every POM vector, it is valid for their convex hull.
	\end{proof}
	
	We call these inequalities \emph{prefix-cover inequalities}. We say that, for every applicant $a$ and every acceptable house $h$, either the house $h$ must be assigned to some applicant, or $a$ must be assigned to a house that appears before $h$ in the preference list of $a$. When $h$ is the first choice of $a$, the set $B_a(h)$ is empty, and the inequality reduces exactly to the first-choice house covering inequality. 
	
	\paragraph{Cutting off a Fractional Vertex.} Consider now the basic relaxation. As previously shown, the vector \eqref{first-fractional-solution} was a fractional vertex of the relaxation. This fractional solution is cut off by the prefix-cover inequality corresponding to the house $h_3$. 
	Indeed, $h_3$ is the first choice of both $a_3$ and $a_4$. 
	Therefore, the prefix-cover inequality reduces to
	\[
	x_{23}+x_{33}+x_{43}\ge 1.
	\]
	However, for the fractional solution above we have
	\[
	x_{23}+x_{33}+x_{43}
	=
	0+\frac{1}{3}+\frac{1}{3}
	=
	\frac{2}{3}<1.
	\]
	Thus the inequality is violated, and the fractional solution is removed after the prefix-cover cuts are added.
	
	\subsection{Safe-holder inequalities}
	
	The second family of inequalities comes from combining trade-in freeness with coalition freeness.
	
	Suppose that applicant $a$ is assigned to a house $h$, and let $g\in P(a)$ be a house such that
	\[
	g\succ_{a} h.
	\]
	In a Pareto optimal matching, the house $g$ must be assigned. Otherwise, applicant $a$ could leave $h$ and take the unmatched house $g$, contradicting trade-in freeness.
	
	However, it is not enough that $g$ is assigned to some applicant. The holder of $g$ must be compatible with the fact that $a$ is assigned to $h$. If $g$ is assigned to an applicant $b$ who prefers $h$ to $g$, then $a$ and $b$ form a two-applicant coalition: applicant $a$ wants $g$, while applicant $b$ wants $h$. Such a matching is not coalition-free.
	
	This motivates the following definition. For $a\in A$, $h\in P(a)$, and $g\in B_a(h)$, define the set of safe holders of $g$ with respect to the assignment $(a,h)$ by
	\[
	S(a,h,g)
	=
	\{b\in Q(g)\setminus\{a\}: h\notin P(b)\ \text{or}\ g\succ_b h\}.
	\]
	Thus $b\in S(a,h,g)$ if $b$ can hold $g$ without creating a two-applicant exchange with $a$. If $h\notin P(b)$, then $b$ does not find $h$ acceptable, so no such exchange can occur. If $h\in P(b)$, then $b$ is safe precisely when $b$ prefers $g$ to $h$.
	
	The corresponding inequality is
	\[
	\boxed{
		x_{ah}
		\le
		\sum_{b\in S(a,h,g)}x_{bg}
	}
	\]
	for every $a\in A$, every $h\in P(a)$, and every $g\in B_a(h)$.
	
	Before proving validity, we give a small example showing why this inequality is useful. Let
	\[
	A=\{a_1,a_2\},
	\qquad
	H=\{h_1,h_2\},
	\]
	with preferences
	\[
	P(a_1)=\langle h_1,h_2\rangle,
	\qquad
	P(a_2)=\langle h_2,h_1\rangle.
	\]
	The unique Pareto optimal matching is
	\[
	M=\{(a_1,h_1),(a_2,h_2)\},
	\]
	where both applicants receive their first choice. The other perfect matching,
	\[
	M'=\{(a_1,h_2),(a_2,h_1)\},
	\]
	is not Pareto optimal, because the two applicants can exchange houses and both improve.
	
	Consider the fractional point
	$x_{11}=x_{12}=x_{21}=x_{22}=\frac{1}{2}.$
	This point satisfies the assignment constraints. It also satisfies the coalition-free inequality corresponding to the two-applicant coalition $\{(a_1,h_2),(a_2,h_1)\}$, because
	$x_{12}+x_{21}=\frac{1}{2}+\frac{1}{2}=1.$
	Thus the coalition inequality is tight, but not violated.
	
	However, this fractional point is not in the convex hull of POM vectors, since the only Pareto optimal matching is $M$. The safe-holder inequality identifies this issue. Take
	\[
	a=a_1,
	\qquad
	h=h_2,
	\qquad
	g=h_1.
	\]
	applicant $a_1$ prefers $h_1$ to $h_2$. The only other applicant who can hold $h_1$ is $a_2$. But $a_2$ prefers $h_2$ to $h_1$. Therefore, $a_2$ is not a safe holder of $h_1$ with respect to the assignment $(a_1,h_2)$. Hence
	$S(a_1,h_2,h_1)=\varnothing.$
	The safe-holder inequality becomes
	$x_{12}\le 0.$
	The fractional point violates this inequality, since
	$x_{12}=\frac{1}{2}.$
	Thus, the safe-holder inequality cuts off a fractional solution that is allowed by the original relaxation.
	
	\begin{pprop}
		For every $a\in A$, every $h\in P(a)$, and every $g\in B_a(h)$, the inequality
		\[
		x_{ah}
		\le
		\sum_{b\in S(a,h,g)}x_{bg}
		\]
		is valid for the Pareto optimal matching polytope.
	\end{pprop}
	
	\begin{proof}
		Let $M$ be a Pareto optimal matching, and let $x$ be its incidence vector. We prove that
		\[
		x_{ah}
		\le
		\sum_{b\in S(a,h,g)}x_{bg}.
		\]
		
		If
		$x_{ah}=0,$
		then the inequality is immediate.
		
		Suppose now that
		$x_{ah}=1.$
		Thus, in $M$, applicant $a$ is assigned to $h$. Since $g\in B_a(h)$, we have
		$g\succ_{a} h.$
		If $g$ were unmatched, applicant $a$ could leave $h$ and take $g$. This would contradict trade-in freeness. Therefore, $g$ must be assigned in $M$.
		
		Let $b$ be the applicant assigned to $g$. Since $a$ is already assigned to $h$, we have $b\ne a$. Therefore,
		$
		b\in Q(g)\setminus\{a\}.
		$
		
		We claim that $b\in S(a,h,g)$. Suppose not. Then $h\in P(b)$ and
		$
		h\succ_b g.
		$
		But then $a$ and $b$ form a two-applicant coalition: applicant $a$, currently assigned to $h$, prefers $g$, while applicant $b$, currently assigned to $g$, prefers $h$. This contradicts coalition freeness.
		
		Therefore, the holder $b$ of $g$ must belong to $S(a,h,g)$. Hence
		$
		\sum_{b'\in S(a,h,g)}x_{b'g}=1.
		$
		Since $x_{ah}=1$, we get
		$
		x_{ah}
		\le
		\sum_{b'\in S(a,h,g)}x_{b'g}.
		$
		
		Thus, the inequality holds for every Pareto optimal matching vector, and therefore it is valid for the Pareto optimal matching polytope.
	\end{proof}
	
	The safe-holder inequalities strengthen the relaxation by enforcing, in a linear way, a condition that is automatic in the integer model. In an integral matching, if $a$ receives $h$ and prefers $g$ to $h$, then $g$ must be assigned to an applicant who does not create a two-applicant coalition with $a$. In the linear relaxation, the original constraints may allow $g$ to be assigned fractionally to unsafe holders. The safe-holder inequalities exclude such fractional configurations.
	
	Together, the prefix-cover inequalities and the safe-holder inequalities capture two different implications of Pareto optimality. The prefix-cover inequalities come from maximality and trade-in freeness, while the safe-holder inequalities combine trade-in freeness with coalition freeness. Both families are valid for the Pareto optimal matching polytope and can be added to the linear relaxation as candidate cutting inequalities.
	
	
	\subsection{Facet-defining inequalities for a cyclic family}
	
	The inequalities introduced in the previous sections are valid for arbitrary house allocation instances. We now study the facial structure of the Pareto optimal matching polytope for a simple parametric family of instances. For this family, we identify a new class of valid inequalities and prove that they define facets of the corresponding polytope.
	
	\paragraph{The cyclic family of instances.}
	Fix an integer $n\ge 3$. Consider the set of houses
	\[
	H=\{h_1,\ldots,h_n\}
	\]
	and the set of applicants
	\[
	A=\{a_1,\ldots,a_n,b_1,\ldots,b_n\}.
	\]
	where indices are taken modulo $n$. The preference lists are
	\[
	P(a_i)=\langle h_{i+1},h_i\rangle,
	\quad i=1,\ldots,n,
	\]
	and
	\[
	P(b_i)=\langle h_i\rangle,
	\quad i=1,\ldots,n.
	\]
	We denote this instance by $\mathcal{I}_n$.
	
	Thus, every applicant $a_i$ finds exactly two houses acceptable. The first choice of $a_i$ is $h_{i+1}$, while the second choice is $h_i$. Every applicant $b_i$ finds only the house $h_i$ acceptable. The acceptable pairs involving the applicants $a_i$ form an even cycle, while each applicant $b_i$ is adjacent only to $h_i$.
	
	For convenience, we introduce the following notation:
	\[
	s_i=x_{a_i h_i},
	\quad
	t_i=x_{a_i h_{i+1}},
	\quad
	r_i=x_{b_i h_i},
	\quad i=1,\ldots,n.
	\]
	Therefore, $s_i$ represents the assignment of applicant $a_i$ to the second choice $h_i$, $t_i$ represents the assignment of $a_i$ to the first choice $h_{i+1}$, and $r_i$ represents the assignment of $b_i$ to the only acceptable house $h_i$.
	
	There are exactly $3n$ acceptable pairs in $\mathcal{I}_n$. Moreover, every house $h_i$ is the first and only choice of applicant $b_i$. Obviously, every house must be assigned in every POM vector. Indeed, if $h_i$ were unmatched, then $b_i$ would also be unmatched, and the pair $(b_i,h_i)$ could be added to the matching, contradicting maximality.
	
	It follows that every POM vector satisfies
	\begin{equation}\label{eq:cyclic-house-assignment}
		s_i+t_{i-1}+r_i=1,
		\quad i=1,\ldots,n.
	\end{equation}
	These $n$ equalities are linearly independent, since each of them contains exactly the variables associated with one house.
	
	Now we will try to describe the structure of the POM vectors of $\mathcal{I}_n$. Consider the undirected graph $G_{n}$ with vertex set
	\[
	V(G_{n})=\{s_1,\ldots,s_n,t_1,\ldots,t_n\},
	\]
	and edge set
	\[
	E(G_{n})
	=
	\bigl\{\{s_i,t_i\}:i=1,\ldots,n\bigr\}
	\cup
	\bigl\{\{t_i,s_{i+1}\}:i=1,\ldots,n\bigr\}.
	\]
	The edge $\{s_i,t_i\}$ represents the fact that applicant $a_i$ cannot receive both $h_i$ and $h_{i+1}$. Similarly, the edge $\{t_i,s_{i+1}\}$ represents the fact that the assignments corresponding to $t_i$ and $s_{i+1}$ both use the house $h_{i+1}$.
	
	Therefore, $G_{n}$ is the undirected cycle on the $2n$ vertices
	\[
	s_1,t_1,s_2,t_2,\ldots,s_n,t_n,
	\]
	appearing in the cyclic order
	\[
	s_1-t_1-s_2-t_2-\cdots-s_n-t_n-s_1.
	\]
	
	\paragraph{Characterization of the POM vectors.}
	The following proposition gives an exact description of the Pareto optimal matchings of $\mathcal{I}_n$.

	\begin{pprop}
		Let $x$ be an incident vector of $\mathcal{I}_n$ $\left( x\in\{0,1\}^{3n} \right)$. Then $x$ is a POM vector of
		$\mathcal{I}_n$ if and only if the following conditions hold:
		\begin{enumerate}
			\item The set
			$S(x) = \{s_i:s_i=1\} \cup \{t_i:t_i=1\}$
			is an independent set of $G_n$.
			
			\item
			$S(x)\ne\{s_1,\ldots,s_n\}.	$
			
			\item For every $i=1,\ldots,n$,
			$r_i=1-s_i-t_{i-1},$
			where the indices are taken modulo $n$.
		\end{enumerate}
	\end{pprop}
	
	\begin{proof}
		Let $M$ be a Pareto optimal matching of $\mathcal{I}_n$ and $x\in\{0,1\}^{3n}$ be a binary vector indexed by the acceptable pairs of $\mathcal{I}_n$. As observed above, every house $h_i$ must be assigned in $M$. Therefore,
		$s_i+t_{i-1}+r_i=1, i=1,\ldots,n.$
		
		Since $M$ is a matching, applicant $a_i$ cannot be assigned simultaneously to $h_i$ and $h_{i+1}$. Hence
		\[
		s_i+t_i\le 1.
		\]
		Moreover, the variables $t_i$ and $s_{i+1}$ correspond to two assignments involving the same house $h_{i+1}$. Thus,
		\[
		t_i+s_{i+1}\le 1.
		\]
		It follows that the set of variables $s_i,t_i$ that are equal to one is a independent set of $G_{n}$.
		
		
		This independent set cannot be $S^{*}$. Indeed, if
		$s_1=\cdots=s_n=1$, then every applicant $a_i$ is assigned to $h_i$ but strictly prefers $h_{i+1}$. Since $h_{i+1}$ is assigned to $a_{i+1}$, the applicants $a_1,a_2,\ldots,a_n$ form a coalition. This contradicts the Pareto optimality of $M$.
		
		For the converse direction, let $S$ be a independent set of $G_{n}$ such that $S\ne S^{*}$. Set the variables $s_i,t_i$ according to the incidence vector of $S$, and define $r_i=1-s_i-t_{i-1}.$ Because $s_i$ and $t_{i-1}$ are adjacent in $G_{n}$, they cannot both be equal to one. Therefore, $r_i\in\{0,1\}.$ The inequalities
		$s_i+t_i\le 1$ ensure that every applicant $a_i$ is assigned to at most one house and from $r_i=1-s_i-t_{i-1}$ that every house $h_i$ is assigned exactly once. Hence the resulting vector is the incidence vector of a matching that assigns every house.
		
		Since every house is assigned, the matching is maximal. It is also trade-in free, because there is no unmatched house to which an applicant could move.
		
		It remains to show that the matching is coalition free. An applicant $b_i$ cannot participate in a coalition, since $h_i$ is the only acceptable house of $b_i$. Similarly, if $t_i=1$, then applicant $a_i$ receives the first choice $h_{i+1}$ and therefore cannot strictly improve.
		
		Consequently, the only applicants who can participate in a coalition are those for which $s_i=1$. Suppose that $s_i=1$. Then $a_i$ is assigned to $h_i$ and strictly prefers $h_{i+1}$. Since
		$s_i+t_i\le 1,$
		we have $t_i=0$. Using the equality for the house $h_{i+1}$, we obtain
		$s_{i+1}+t_i+r_{i+1}=1,$
		and hence
		$s_{i+1}+r_{i+1}=1.$
		
		If $s_{i+1}=1$, then $h_{i+1}$ is assigned to $a_{i+1}$, and a possible coalition can continue from $a_i$ to $a_{i+1}$. If $s_{i+1}=0$, then $r_{i+1}=1$, so $h_{i+1}$ is assigned to $b_{i+1}$. In this case the sequence cannot continue, since $b_{i+1}$ does not prefer any other house.
		
		Therefore, a sequence of applicants who can cyclically improve can continue from $a_i$ to $a_{i+1}$ only when $s_{i+1}=1$. Such a sequence forms a directed cycle only if
		\[
		s_1=\cdots=s_n=1.
		\]
		However, this is exactly the independent set $S^{*}$, which has been excluded. Hence the matching is coalition free.
		
		The resulting matching is maximal, trade-in free, and coalition free, so it is Pareto optimal.
	\end{proof}
	
	\paragraph{Dimension.}
	We can now determine the dimension of the Pareto optimal matching polytope of $\mathcal{I}_n$.
	
	\begin{pprop}
		For every $n\ge 3$,
		\[
		\dim\bigl(P_{\mathrm{POM}}(\mathcal{I}_n)\bigr)=2n.
		\]
	\end{pprop}
	
	\begin{proof}
		The instance $\mathcal{I}_n$ has $3n$ acceptable pairs. Because every POM vector satisfies the $n$ linearly independent equalities
		$s_i+t_{i-1}+r_i=1, i=1,\ldots,n$
		we get
		\[
		\dim\bigl(P_{\mathrm{POM}}(\mathcal{I}_n)\bigr)
		\le 3n-n
		=2n.
		\]
		
		We prove the reverse inequality by constructing $2n+1$ affinely independent POM vectors. For a variable $q$, let $e_q$ denote the corresponding unit vector in $\mathbb{R}^{3n}$. First, consider the POM vector
		\[
		x^{0}=\sum_{k=1}^{n}e_{r_k}.
		\]
		This is the incidence vector of the matching in which every applicant $b_k$ is assigned to $h_k$.
		
		For every $i=1,\ldots,n$, define
		\[
		x^{s_i}=x^{0}+e_{s_i}-e_{r_i}.
		\]
		This is the incidence vector of the matching in which $a_i$ is assigned to $h_i$, while every $b_k$ with $k\ne i$ is assigned to $h_k$.
		
		Similarly, define
		\[
		x^{t_i}=x^{0}+e_{t_i}-e_{r_{i+1}}.
		\]
		This is the incidence vector of the matching in which $a_i$ is assigned to the first choice $h_{i+1}$, while every $b_k$ with $k\ne i+1$ is assigned to $h_k$.
		
		By the previous proposition, all these vectors are POM vectors. To prove affine independence, it is enough to show that the $2n$ vectors
		\[
		x^{s_i}-x^{0}=e_{s_i}-e_{r_i},
		\quad i=1,\ldots,n,
		\]
		and
		\[
		x^{t_i}-x^{0}=e_{t_i}-e_{r_{i+1}},
		\quad i=1,\ldots,n,
		\]
		are linearly independent.
		
		Suppose that
		\[
		\sum_{i=1}^{n}\alpha_i
		\bigl(e_{s_i}-e_{r_i}\bigr)
		+
		\sum_{i=1}^{n}\beta_i
		\bigl(e_{t_i}-e_{r_{i+1}}\bigr)
		=0.
		\]
		For each $i$, the coordinate $s_i$ appears only in the vector
		$e_{s_i}-e_{r_i}.$
		Therefore, $\alpha_i=0$ for every $i$. Similarly, the coordinate $t_i$ appears only in
		$e_{t_i}-e_{r_{i+1}},$
		and hence $\beta_i=0$ for every $i$.
		
		Thus, the $2n$ difference vectors are linearly independent, and the $2n+1$ POM vectors
		\[
		x^{0},
		\quad
		x^{s_1},\ldots,x^{s_n},
		\quad
		x^{t_1},\ldots,x^{t_n}
		\]
		are affinely independent. Therefore,
		\[
		\dim\bigl(P_{\mathrm{POM}}(\mathcal{I}_n)\bigr)\ge 2n.
		\]
		Combining the two inequalities gives
		\[
		\dim\bigl(P_{\mathrm{POM}}(\mathcal{I}_n)\bigr)=2n.
		\]
	\end{proof}
	
	\paragraph{Cycle-break inequalities.}
	The cyclic structure of $\mathcal{I}_n$ gives rise to the following inequalities:
	\begin{equation}\label{eq:cycle-break-inequality}
		t_j+\sum_{i=1}^{n}r_i\ge 1,
		\qquad j=1,\ldots,n.
	\end{equation}
	We call these inequalities \emph{cycle-break inequalities}.
	
	The interpretation is the following. In a Pareto optimal matching, either applicant $a_j$ must receive the first choice $h_{j+1}$, or at least one house must be assigned to a backup applicant $b_i$. If neither event occurs, then every $a_i$ receives the second choice $h_i$, and the applicants form a cyclic coalition.
	
	Summing the affine equalities
	\[
	s_i+t_{i-1}+r_i=1
	\]
	over all $i$ gives
	\begin{equation}\label{eq:cyclic-affine-sum}
		\sum_{i=1}^{n}s_i
		+
		\sum_{i=1}^{n}t_i
		+
		\sum_{i=1}^{n}r_i
		=n.
	\end{equation}
	Therefore, on the affine hull of $P_{\mathrm{POM}}(\mathcal{I}_n)$, the cycle-break inequality corresponding to $j$ is equivalent to
	\begin{equation}\label{eq:equivalent-cycle-break-inequality}
		\sum_{i=1}^{n}s_i
		+
		\sum_{\substack{i=1\\i\ne j}}^{n}t_i
		\le n-1.
	\end{equation}
	Thus, the cycle-break inequality can also be viewed as a lifting of the coalition inequality associated with the cyclic assignment $\{s_1,\ldots,s_n\}.$
	
	\begin{ttheorem}
		For every $n\ge 3$ and every $j\in\{1,\ldots,n\}$, the cycle-break inequality
		\[
		t_j+\sum_{i=1}^{n}r_i\ge 1
		\]
		defines a facet of $P_{\mathrm{POM}}(\mathcal{I}_n)$.
	\end{ttheorem}
	
	\begin{proof}
		We first prove validity. Let $M$ be a Pareto optimal matching of $\mathcal{I}_n$, and let $x$ be its incidence vector.
		
		If $r_i=1$ for at least one $i$, then
		$t_j+\sum_{i=1}^{n}r_i\ge 1$
		holds immediately.
		
		Suppose now that
		$r_i=0,i=1,\ldots,n.$
		Since every house is assigned, all $n$ houses must then be assigned to the $n$ applicants $a_1,\ldots,a_n$. Consequently, every applicant $a_i$ is matched.
		
		Suppose, for contradiction, that $t_j=0$. Since $a_j$ is matched and the only acceptable houses of $a_j$ are $h_j$ and $h_{j+1}$, we must have
		$s_j=1.$
		Using the equality for the house $h_{j+1}$, we obtain
		$s_{j+1}+t_j+r_{j+1}=1.$
		Since $t_j=r_{j+1}=0$, this gives
		$s_{j+1}=1.$
		Repeating the same argument cyclically gives
		$s_1=\cdots=s_n=1.$
		However, it is easy to see that this assignment contains the coalition
		$a_1,a_2,\ldots,a_n,$
		and therefore it is not Pareto optimal. This is a contradiction. Hence $t_j=1$, and the cycle-break inequality is valid.
		
		We next prove that the inequality defines a facet. By the previous proposition,
		$\dim\bigl(P_{\mathrm{POM}}(\mathcal{I}_n)\bigr)=2n.$
		Therefore, it is enough to construct $2n$ affinely independent POM vectors that satisfy the cycle-break inequality with equality. Fix an inequality $j$. We define the following matchings.
		
		For every $k=1,\ldots,n$, define the matching
		\begin{equation}
			R^k
			=
			\{(a_\ell,h_\ell):\ell\ne k\}
			\cup
			\{(b_k,h_k)\}.
		\end{equation}
		In this matching, all applicants $a_\ell$ except $a_k$ receive their second choice, while $b_k$ receives $h_k$.
		
		For every $i\in\{1,\ldots,n\}$, define
		\begin{equation}
			T^i
			=
			\{(a_\ell,h_\ell):\ell\notin\{i,i+1\}\}
			\cup
			\{(a_i,h_{i+1}),(b_i,h_i)\}.
		\end{equation}
		In this matching, $a_i$ receives the first choice $h_{i+1}$,
		$b_i$ receives $h_i$, applicant $a_{i+1}$ is unmatched, and every
		applicant $a_\ell$ with $\ell\notin\{i,i+1\}$ receives $h_\ell$.
		
		For the fixed index $j$, we use the $n-1$ matchings $T^i, \forall i\ne j$.
		Indeed, if $i\ne j$, then $t_j=0$ and $r_i=1$ in $T^i$, so
		\[
		t_j+\sum_{k=1}^{n}r_k=1.
		\]
		Thus, $T^i$ satisfies the cycle-break inequality corresponding to $j$
		with equality. The matching $T^j$ is not used, since it has
		$t_j=r_j=1$ and therefore does not satisfy the inequality with equality.
		
		Finally, define
		\begin{equation}
			Z = \{(a_i,h_{i+1}):i=1,\ldots,n\}.
		\end{equation}
		In $Z$, every applicant $a_i$ receives the first choice.
		
		By the characterization of the POM vectors, all the matchings
		$R^1,\ldots,R^n, T^i, \forall i\ne j, Z$ are Pareto optimal.
		
		They also satisfy the cycle-break inequality with equality. Indeed, in $R^k$, we have
		$t_j=0,\sum_{i=1}^{n}r_i=1.$
		In $T^i$, where $i\ne j$, we also have
		$t_j=0,\sum_{k=1}^{n}r_k=1.$
		Finally, in $Z$ we have
		$t_j=1,\sum_{i=1}^{n}r_i=0.$
		
		There are $n+(n-1)+1=2n$ such POM vectors. It remains to prove that they are affinely independent.
		
		Let $x^{R^k}$, $x^{T^i}$, and $x^Z$ denote their incidence vectors. Suppose that
		\begin{equation}\label{eq:affine-dependence-cycle-break}
			\sum_{k=1}^{n}\lambda_k x^{R^k}
			+
			\sum_{\substack{i=1\\i\ne j}}^{n}\mu_i x^{T^i}
			+
			\nu x^Z
			=0,
		\end{equation}
		where
		\begin{equation}\label{eq:affine-coefficient-sum-cycle-break}
			\sum_{k=1}^{n}\lambda_k
			+
			\sum_{\substack{i=1\\i\ne j}}^{n}\mu_i
			+
			\nu
			=0.
		\end{equation}
		
		Consider $t_j$. Among all the vectors appearing in \eqref{eq:affine-dependence-cycle-break}, only $x^Z$ has value one in this coordinate (as described before). Therefore, $\nu=0.$
		
		Next, fix some $i\ne j$ and consider $t_i$. The only vectors with value one in this coordinate are $x^{T^i}$ and $x^Z$. Hence
		$\mu_i+\nu=0.$
		Since $\nu=0$, we obtain
		$\mu_i=0,i\ne j.$
		
		Equation \eqref{eq:affine-coefficient-sum-cycle-break} now gives
		$\sum_{k=1}^{n}\lambda_k=0.$
		
		Finally, fix $k\in\{1,\ldots,n\}$ and consider the coordinate $r_k$. Among the vectors $x^{R^1},\ldots,x^{R^n}$, only $x^{R^k}$ has value one in the coordinate $r_k$. Therefore,
		$\lambda_k=0.$
		Since this holds for every $k\in\{1,\ldots,n\}$, all coefficients $\lambda_k$ are zero.
	
		Thus all coefficients in the affine dependence are zero, and the $2n$ POM vectors are affinely independent. Hence the face induced by the cycle-break inequality has dimension at least
		$2n-1.$
		The inequality is not an affine equality for the polytope. For example, for the POM vector $x^0$ in which every $b_i$ receives $h_i$, we have
		$
		t_j+\sum_{i=1}^{n}r_i=n>1.
		$
		Therefore, the induced face is a proper face and has dimension exactly
		$
		2n-1.
		$
		As a result, the cycle-break inequality defines a facet of
		$P_{\mathrm{POM}}(\mathcal{I}_n)$.
	\end{proof}
	
	\paragraph{Cutting off a fractional point.}
	We finally show that the cycle-break inequalities are not implied by the original relaxation together with the prefix-cover and safe-holder inequalities.
	
	Consider the fractional point $\bar{x}$ given by
	\begin{equation}\label{eq:cyclic-fractional-point}
		\bar{s}_i=\frac{1}{2},
		\qquad
		\bar{t}_i=\frac{1}{2},
		\qquad
		\bar{r}_i=0,
		\qquad i=1,\ldots,n.
	\end{equation}
	The applicant matching constraints are satisfied, since $\bar{s}_i+\bar{t}_i=1.$ The house matching constraints are also satisfied with equality: $\bar{s}_i+\bar{t}_{i-1}+\bar{r}_i = \frac{1}{2}+\frac{1}{2}+0 = 1.$
	
	The maximality constraints are satisfied. Every applicant $a_i$ is fully matched, while, for applicant $b_i$, the house $h_i$ is fully assigned to other applicants.
	
	The only nontrivial trade-in constraint for $a_i$ corresponds to the first-choice house $h_{i+1}$. Its left-hand side is $1-\bar{s}_i = \frac{1}{2} \ge 0.$ All remaining trade-in constraints are also satisfied.
	
	The unique coalition inequality is $\sum_{i=1}^{n}s_i\le n-1.$ At $\bar{x}$, its left-hand side is $\sum_{i=1}^{n}\bar{s}_i = \frac{n}{2} \le n-1,$ where the last inequality follows from $n\ge 3$.
	
	Every house is fully assigned at $\bar{x}$, so all prefix-cover inequalities are satisfied. Moreover, each safe-holder inequality becomes $\bar{s}_i \le \bar{s}_{i+1}+\bar{r}_{i+1},$ which is satisfied with equality, since $\frac{1}{2} = \frac{1}{2}+0.$
	
	However, for every $j=1,\ldots,n$, the corresponding cycle-break inequality is violated: $\bar{t}_j+\sum_{i=1}^{n}\bar{r}_i = \frac{1}{2} < 1.$ Therefore, the cycle-break inequalities strictly strengthen the relaxation obtained by adding the prefix-cover and safe-holder inequalities.
	
	\paragraph{A small example.}
	For $n=3$, the preference lists are
	\[
	P(a_1)=\langle h_2,h_1\rangle,
	\qquad
	P(a_2)=\langle h_3,h_2\rangle,
	\qquad
	P(a_3)=\langle h_1,h_3\rangle,
	\]
	and
	\[
	P(b_i)=\langle h_i\rangle,
	\qquad i=1,2,3.
	\]
	The corresponding Pareto optimal matching polytope has dimension
	\[
	\dim\bigl(P_{\mathrm{POM}}(\mathcal{I}_3)\bigr)=6.
	\]
	For example, the cycle-break inequality corresponding to $j=3$ is
	\[
	x_{a_3h_1}
	+
	x_{b_1h_1}
	+
	x_{b_2h_2}
	+
	x_{b_3h_3}
	\ge 1.
	\]
	By the previous theorem, this inequality defines a facet of
	$P_{\mathrm{POM}}(\mathcal{I}_3)$.
	
	We get the same inequality (as $X_{31} + X_{41} + X_{52} + X_{63} \ge 1$) for this example from the polyhedral analysis in our project.

\chapter{Conclusions and Future Work}

	This thesis studied matching problems from two complementary perspectives, the design and analysis of combinatorial algorithms, and the formulation of discrete problems through linear and integer programming.
	
	In Chapter $1$, we considered two classical problems of matching theory from an algorithmic perspective. We first studied the maximum bipartite matching
	problem, beginning with the classical augmenting-path algorithm and then
	presenting the Hopcroft–Karp algorithm, which achieves a significantly better
	running time by processing several shortest augmenting paths in each phase.
	We then examined the stable marriage problem and the Gale–Shapley algorithm.
	We paid special attention on the presentation of the algorithms.
	
	In Chapter $2$, we revisited the same problems but now using linear and integer programming. We studied the standard integer programming formulations for the maximum bipartite matching and stable marriage problems. In both cases, the corresponding linear relaxations are integral. Hence, the original discrete problems can be solved through linear programming without explicitly enforcing the binary restrictions on the variables.
	
	Chapter $3$ focused on Pareto optimal matchings in the one-to-one house allocation model. Starting from an integer programming formulation of the problem, we constructed an explicit fractional vertex of its linear relaxation and thereby showed that, unlike the formulations studied in the preceding chapter, the relaxation is not integral. Since the family of coalition-free constraints may be factorial in size, we developed a separation procedure based on an auxiliary directed graph and the Floyd–Warshall algorithm. The resulting procedure has running time $O(n^{3}L^{3})$, where $n$ is the number of applicants and $L$ is the maximum length of a preference list. In particular, this becomes $O(n^{6})$ when there are $n$ applicants and $n$ houses. We also performed computational experiments on several small instances. For each instance, the Pareto optimal matching vectors were generated and their convex hull was constructed using SageMath. Its linear description was then compared with fractional vertices of the original relaxation. This analysis made it possible to identify relations that are valid for the Pareto optimal matching polytope but are not enforced by the relaxation. We further showed that $\dim(P_{\mathrm{POM}})\le |E|-|F|$ where $E$ is the set of acceptable applicant–house pairs and $F$ is the set of houses that appear as the first choice of at least one applicant. Finally, we derived and proved the validity of two families of problem-specific inequalities, the prefix-cover inequalities and the safe-holder inequalities. Both families strengthen the relaxation by removing fractional solutions that do not belong to the convex hull of Pareto optimal matching vectors.
	
	Finally, we studied the facial structure of the Pareto optimal matching polytope for a cyclic parametric family of house allocation instances. For this family, we introduced a family of cycle-break inequalities and proved that each of these inequalities is \emph{facet-defining}. Of course this facet result concerns a specific structured family and does not provide a general facet description of the Pareto optimal matching polytope for arbitrary house allocation instances. Extending this approach to broader classes of instances would require substantially more work.
	
	From the above results, we see that some integer programming formulations have integral linear relaxations, and therefore an integral optimal solution can be obtained by solving the corresponding linear program. In other cases, integrality is lost, and the relaxation contains fractional vertices that cannot be expressed as convex combinations of the incidence vectors of feasible integer solutions. The separation procedure, the computational experiments, and the additional valid inequalities developed in this thesis provide a first step towards a tighter polyhedral description of the Pareto optimal matching polytope.
	
	An important direction for future work is to determine whether the prefix-cover inequalities, the safe-holder inequalities, or other relevant inequalities are facet-defining under suitable conditions. It would also be interesting to investigate whether the cycle-break inequalities can be extended beyond the cyclic family considered in this thesis, or whether analogous inequalities arise from other structures. Such a study would require a more complete characterization of the affine hull of the Pareto optimal matching polytope. In several of the examined instances, its dimension was strictly
	smaller than the bound $|E|-|F|$, demonstrating the existence of additional
	independent affine equalities. Further research could also investigate new
	families of valid inequalities and evaluate their computational effect on larger instances.
	
	The computational framework developed in this thesis provides a basis for such
	investigations. For small instances, it generates the incidence vectors of all
	Pareto optimal matchings, constructs their convex hull and its
	$H$-description, and identifies the equations and inequalities violated by
	fractional points of the relaxation. It can therefore be used to formulate,
	test, and refine conjectures concerning the dimension, affine hull, facets, and general polyhedral structure of the Pareto optimal matching polytope.

\chapter{Implementation Details and Usage Guide}

	This project was developed in order to study the polytope of Pareto optimal matchings in the House Allocation problem. The main goal is to compare two objects. The first one is the true convex hull of all Pareto optimal matching vectors. The second one is the polytope defined by the linear programming relaxation of the integer programming model. By comparing them, we can find fractional solutions of the relaxation and identify valid inequalities that are missing from the relaxation.

	The program follows the same pipeline for every input instance. First, it reads a preference instance from a CSV file. Then it runs the Serial Dictatorship algorithm for all possible orders of the applicants. This gives all the Pareto optimal matchings. There can be duplicates (which we remove) because different applicant orders can produce the same matching. The remaining unique Pareto optimal matchings are converted into incidence vectors, called POM vectors. We use these vectors to construct the convex hull with SageMath. From convex hull, the program extracts the H-description.

	After that, the program solves the LP relaxation of the integer programming model. The coalition-free constraints are not added all at once, because there may be exponentially many of them. Instead, they are added by a separation procedure. The program searches for a fractional solution of the relaxation by solving the LP with several random objective functions. If a fractional solution is found, it is compared with the H-description of the true convex hull. The final output shows which equations and inequalities of the true polytope are violated by the fractional relaxation solution.
	
	\section{Project Structure}
	
	The project has the following main folders and files:
	
	\begin{verbatim}
		data/
		sd/
		lp_relaxation/
		polyhedral_analysis/
		results/
		main.py
		README.txt
	\end{verbatim}
	
	The folder \texttt{data/} contains the input instances. Each instance is a CSV file containing the preference lists of the applicants.
	
	The folder \texttt{sd/} contains the implementation of Serial Dictatorship. This part generates Pareto optimal matchings and writes them in vector form.
	
	The folder \texttt{lp\_relaxation/} contains the implementation of the LP relaxation of the integer programming model. It also contains the separation procedure for the coalition-free constraints.
	
	The folder \texttt{polyhedral\_analysis/} contains the code that builds the convex hull of the Pareto optimal matching vectors and extracts its H-description.
	
	The folder \texttt{results/} contains the output files. For each input instance, a separate folder is created.
	
	The file \texttt{main.py} runs the complete experiment for one selected instance.
	
	\section{Input Files}
	
	Each input instance is stored as a CSV file in the folder \texttt{data/}. The first column is called \texttt{applicant}. The remaining columns are called \texttt{pref1}, \texttt{pref2}, and so on. They contain the houses in decreasing order of preference.
	
	For example:
	
	\begin{verbatim}
		applicant,pref1,pref2,pref3,pref4
		1,1,2,4,
		2,1,3,2,
		3,3,5,1,4
		4,3,2,5,
		5,2,1,,
	\end{verbatim}
	
	This means that applicant 1 prefers house 1 first, then house 2, then house 4. Empty entries mean that the applicant has no more acceptable houses.
	
	In the current implementation, the input files follow a simple convention: applicants are numbered consecutively as \(1,2,\ldots,n\). The examples used in the experiments are small instances.
	
	\section{The Main File}
	
	The file \texttt{main.py} controls the whole experiment. The instance is selected by changing the following line:
	
	\begin{verbatim}
		instance = "instance1"
	\end{verbatim}
	
	Then the following steps are executed:
	
	\begin{enumerate}
		\item Run Serial Dictatorship:
		\begin{verbatim}
			sd.sd_alg(instance)
		\end{verbatim}
		
		\item Read the POM vectors:
		\begin{verbatim}
			variables, vertices = ip_convex_hull.read_vector_csv(instance)
		\end{verbatim}
		
		\item Construct the convex hull and extract its H-description:
		\begin{verbatim}
			convex_hull = ip_convex_hull.polyhedral_analysis(instance, variables, vertices)
		\end{verbatim}
		
		\item Solve the LP relaxation and search for a fractional solution:
		\begin{verbatim}
			fractional_solution = relaxation.lp_solve(instance)
		\end{verbatim}
		
		\item If a fractional solution is found, compare it with the H-description of the true polytope:
		\begin{verbatim}
			ip_convex_hull.check_fractional_vertex(
			instance,
			convex_hull,
			variables,
			fractional_solution
			)
		\end{verbatim}
	\end{enumerate}
	
	If no fractional solution is found, the program prints:
	
	\begin{verbatim}
		No fractional vertex was found
	\end{verbatim}
	
	\section{Serial Dictatorship Implementation}
	
	The file \texttt{sd/sd\_alg.py} implements the Serial Dictatorship part of the experiment.
	
	The function \texttt{read\_preferences} reads the CSV file and stores the preferences in a dictionary. For example, if applicant 1 has preference list \(1,2,4\), then this is stored as:
	
	\[
	P(1) = [1,2,4].
	\]
	
	The function \texttt{serial\_dictatorship} considers all permutations of the applicants. For each permutation, the applicants are processed in that order. Each applicant receives the best available house in the applicant's preference list, if such a house exists. If there is no such house, the applicant remains unmatched. This produces one Pareto optimal matching for each ordering of the applicants.
	
	Since different permutations may produce the same matching, the function \texttt{get\_unique\_matchings} removes duplicates. The unique matchings are then written to the results folder.
	
	The function \texttt{write\_pom\_vectors} converts each unique matching into an incidence vector. For every acceptable pair $(a,h)$, there is a variable $X_{ah}$. The value is $1$ if applicant $a$ is matched to house $h$, and 0 otherwise.
	
	The same file also computes simple statistics, such as the number of unique matchings, the minimum and maximum matching size, variables that are never used, and variables that are always used.
	
	\section{Polyhedral Analysis}
	
	The file \texttt{polyhedral\_analysis/ip\_h\_description.py} builds the true Pareto optimal matching polytope.
	
	The function \texttt{read\_vector\_csv} reads the POM vectors from the file:
	
	\begin{verbatim}
		results/<instance>/<instance>_pom_vectors.csv
	\end{verbatim}
	
	Each row is treated as one vertex of the polytope. The variables are read from the column names, such as \texttt{X11}, \texttt{X23}, and so on (this only works for single-digit applicants/houses like X34. It breaks for X101, X112, etc. This limitation will be addressed in future versions).
	
	The function \texttt{polyhedral\_analysis} constructs the convex hull using SageMath:
	
	\[
	\operatorname{conv}\{x^1,x^2,\ldots,x^k\},
	\]
	
	where each \(x^i\) is a POM vector. SageMath is then used to compute the H-description of this polytope. The H-description consists of equations and inequalities.
	
	The output is written to:
	
	\begin{verbatim}
		results/<instance>/<instance>_polyhedral_analysis.txt
	\end{verbatim}
	
	This file contains the dimension of the convex hull, the number of vertices, the equations, and the inequalities.
	
	The function \texttt{check\_fractional\_vertex} compares a fractional solution of the LP relaxation with the H-description of the true polytope. It checks which equations and inequalities are satisfied and which are violated.
	
	\section{LP Relaxation and Separation}
	
	The file \texttt{lp\_relaxation/lp\_relaxation\_separation.py} implements the LP relaxation of the integer programming model.
	
	For every acceptable pair \((a,h)\), the model has a variable:
	
	\[
	x_{ah}.
	\]
	
	In the integer programming model, this variable is binary. In the LP relaxation, it is continuous:
	
	\[
	0 \leq x_{ah} \leq 1.
	\]
	
	The relaxation contains the matching constraints. Each applicant can receive at most one house:
	
	\[
	\sum_{h \in P(a)} x_{ah} \leq 1.
	\]
	
	Each house can be assigned to at most one applicant:
	
	\[
	\sum_{a \in Q(h)} x_{ah} \leq 1.
	\]
	
	The model also contains maximality constraints and trade-in-free constraints. These are part of the original model for Pareto optimal matchings.
	
	In the final version of the implementation, the LP relaxation is also strengthened with the prefix-cover inequalities and the safe-holder inequalities introduced in the previous chapter. These inequalities are valid for the Pareto optimal matching polytope and are added before the separation procedure for coalition-free constraints is applied.
	
	The coalition-free constraints are handled differently. They may be exponentially many, so the program does not add all of them at the beginning. Instead, it solves the current relaxation and then searches for a violated coalition constraint. If one is found, it is added to the LP, and the LP is solved again. This is called separation.
	
	The separation procedure builds a directed graph whose vertices are acceptable pairs $(a,h)$. Every plausible coalition corresponds to a directed cycle in this graph. The graph may also contain additional directed cycles that do not correspond to plausible coalitions, because an applicant or a house may appear more than once. However, such cycles cannot produce violated inequalities for points satisfying the matching constraints. For a plausible coalition $C$, the corresponding constraint is:
	
	\[
	\sum_{(a,h)\in C} x_{ah} \leq |C|-1.
	\]
	
	The code searches for violated coalition constraints using shortest path computations. If the current LP solution violates a coalition constraint, that constraint is added to the model.
	
	The program also uses random objective functions in order to search for fractional vertices of the relaxation. If a fractional solution is found, the values are converted to exact rational numbers using SageMath.
	
	Since GLPK returns numerical values as floating-point numbers, the code converts them to exact rational numbers before comparing them with the H-description of the convex hull. This is done with the function \texttt{to\_QQ}. Values that are very close to 0 or 1 are rounded to exactly $0$ or $1$, while the remaining values are converted to rational numbers using bounded denominators. This is important because the polyhedral computations in SageMath use the rational field $\mathbb{Q}$. Therefore, after this conversion, equations and inequalities can be checked exactly, avoiding small numerical errors such as $0.999999999$ instead of $1$.
	
	\section{Output Files}
	
	For every instance, the program creates a folder:
	
	\begin{verbatim}
		results/<instance>/
	\end{verbatim}
	
	For example, for \texttt{instance1}, the output folder is:
	
	\begin{verbatim}
		results/instance1/
	\end{verbatim}
	
	The main output files are described below.
	
	\paragraph{\texttt{<instance>\_sd\_pareto\_matchings.csv}}
	
	This file contains the result of Serial Dictatorship for every permutation of the applicants.
	
	It has two columns:
	
	\begin{itemize}
		\item \texttt{order}: the order in which the applicants were processed;
		\item \texttt{matching}: the matching produced by that order.
	\end{itemize}
	
	The entries in \texttt{matching} are written in the same order as the applicants in \texttt{order}. Thus, the first entry of \texttt{matching} is the house assigned to the first applicant in \texttt{order}, the second entry is the house assigned to the second applicant in \texttt{order}, etc. The value $-1$ means that the corresponding applicant is unmatched.
	
	This file may contain duplicate matchings, because different applicant orders can lead to the same matching.
	
	\paragraph{\texttt{<instance>\_unique\_pareto\_matchings.csv}}
	
	This file contains only the unique Pareto optimal matchings.
	
	The columns are:
	
	\begin{verbatim}
		A1,A2,A3,...
	\end{verbatim}
	
	Each row gives one matching. The value in column \texttt{Ai} is the house assigned to applicant \(i\). The value \(-1\) means that the applicant is unmatched.
	
	\paragraph{\texttt{<instance>\_pom\_vectors.csv}}
	
	This file contains the incidence vectors of the unique Pareto optimal matchings.
	
	Each column corresponds to a variable \(X_{ah}\). For example, the column \texttt{X23} corresponds to the pair \((2,3)\), meaning applicant 2 matched to house 3.
	
	Each row corresponds to one unique Pareto optimal matching. A value of 1 means that the pair is used in that matching. An empty cell means 0.
	
	These vectors are the vertices used to construct the convex hull.
	
	\paragraph{\texttt{<instance>\_matching\_statistics.txt}}
	
	This file contains simple statistics about the unique Pareto optimal matchings.
	
	It includes:
	
	\begin{itemize}
		\item the number of unique matchings;
		\item the minimum matching size;
		\item the maximum matching size;
		\item which matchings have minimum or maximum size;
		\item variables that are never equal to 1;
		\item variables that are equal to 1 in every matching.
	\end{itemize}
	
	This file is useful for understanding the structure of the instance before studying the full polytope.
	
	\paragraph{\texttt{<instance>\_polyhedral\_analysis.txt}}
	
	This file contains the H-description of the true Pareto optimal matching polytope.
	
	It includes:
	
	\begin{itemize}
		\item the dimension of the convex hull;
		\item the number of vertices;
		\item the equations of the convex hull;
		\item the inequalities of the convex hull.
	\end{itemize}
	
	The inequalities in this file are important because they describe the facets or valid inequalities of the true polytope. By comparing them with the LP relaxation, we can see which inequalities are missing from the relaxation.
	
	\paragraph{\texttt{<instance>\_fractional\_vertex\_hdescription\_check.txt}}
	
	This file is created after the LP relaxation finds a fractional solution.
	
	It contains:
	
	\begin{itemize}
		\item the nonzero coordinates of the fractional solution;
		\item the number of variables;
		\item the number of violated equations;
		\item the number of satisfied equations;
		\item the number of violated inequalities;
		\item the number of satisfied inequalities;
		\item the actual violated inequalities and their residual values.
	\end{itemize}
	
	For an inequality, the program prints the value of:
	
	\[
	\text{lhs} - \text{rhs}.
	\]
	
	If this value is negative, then the inequality is violated by the fractional relaxation solution.
	
	This file is one of the most important outputs of the experiment. It shows exactly which inequalities of the true polytope cut off the fractional point.
	
	\section{How to Run an Experiment}
	
	To run an experiment, first choose the instance in \texttt{main.py}. For example:
	
	\begin{verbatim}
		instance = "instance1"
	\end{verbatim}
	
	Then run the main file in an environment where SageMath and GLPK are available. SageMath can be downloaded and installed by following the official installation guide:
	
	\begin{center}
		\url{https://doc.sagemath.org/html/en/installation/index.html}
	\end{center}
	
	For example, the program can be executed with:
	
	\begin{verbatim}
		sage -python main.py
	\end{verbatim}
	
	Alternatively, if the Python interpreter is already configured to use SageMath, the file can be run directly from the IDE.
	
	After the program finishes, the output files are written in:
	
	\begin{verbatim}
		results/<instance>/
	\end{verbatim}
